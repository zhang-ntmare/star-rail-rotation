# 50 环境区

**管**：本期场地给什么、什么时候生效、影响谁的哪一项。
**不管**：常驻规则（→ 10）；角色自带 buff（→ 30）。

## 场地 buff 必须按「生效范围 + 触发方式」分类

| 维度 | 取值 | 为什么要分 |
|---|---|---|
| 生效范围 | 全队 / 指定命途 / 指定属性 / 指定角色 | 决定能不能吃到 |
| 触发方式 | 常驻 / 进场 / 波次开始 / 阶段开始 / 条件触发 | 决定什么时点算进去 |
| 效果类型 | 数值（攻/速/双暴/增伤）/ 拉条 / 回能 / 特殊规则 | 决定落在四层的哪一层 |
| 持续时间 | 无限 / N 回合 / 本波次 / 本阶段 | 决定要不要续 |

## 按「机制同构」归档，不按期数

同一个效果会在不同期反复出现（击破充满能量、击破全体拉条这类）。**归到族里，不新建"第 N 期"条目** —— 否则每期长一堆，越攒越查不动。

| 同构族 | 见过的形态 | 建模方式 |
|---|---|---|
| 击破 → 全体回能 | 「击破充满能量」 | 破韧事件 → 全体能量拉满 |
| 击破 → 全体拉条 | 「击破全体拉条」 | 破韧事件 → 全员 advance X%（→ `20-action` 登记算子） |
| 击破 → 解控 + 激活终结技 | 4.7 末日三节点通用 | 破韧事件 → 全队 Q 可用 + 控解除（**排轴含义：破韧前把 Q 全交掉，破韧瞬间再爆发一轮**） |
| 进场 → 面板加速 | 贪饕愿力 Lv.3「全队 SPD+12」 | **A 类改面板**，进引擎前先加 |
| 破韧 → 受伤提升 | 坚防守备「破韧后受伤 +100%、首领受伤 −50%」 | 破韧态独立乘区 |
| 破韧 → 敌方延后 | 「破韧后行动额外延后」 | 敌方 AV 位移（→ `20-action`） |
| 欢愉伤害 → 加速解除次数盾 | 4.7 帕姆王【破晓力场】：16 层盾，受击 −1、**欢愉伤害 −2** | 次数型闸门：按"攻击次数×属性"扣层，**不看伤害量**（→ `10-basics/韧性条口径` 的姊妹：次数盾口径） |
| 条件增伤 | 按命途 / 属性 / 欢愉度给增伤 | 常驻乘区，进场即算 |

新期遇到旧族 → 加到该族下面一行，**不新开一节**。

## 缺口

- 历期环境**已有可查源**：`hsr-trend.cduyzh.top/season/doom/{期号}` 的「本期环境与节点效果」一节会印**环境效果 + 每个节点的三选一效果原文**（含全部数值档位）。往后不靠攻略转述，直接抄原文 + 记数据版本。见 `80-tools/数据源-cduyzh三站.md`。

## 写入规则

- 一条环境写一行：`同构族 | 本期形态 | 数值 | 触发 | 来源`，并带 `game_ver`。
- **来源优先写 `hsr-trend /season/... (数据版本 x.y.z)`**，其次才是攻略。
- 影响拉条的必须同时在 `20-action` 登记一个算子，否则引擎会漏算。
- 影响面板速度的按 **A 类**处理（先改 SPD 再算 AV），**不要当拉条**。
