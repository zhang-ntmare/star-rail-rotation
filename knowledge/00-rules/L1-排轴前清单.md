# L1 排轴前清单

> 每份 ≤25 条。这不是建议，是**做之前逐条打勾**。
> 四层递进：骨架 → 拉条 → 机制 → 对账。每层有独立的产出和验收，不许跳层。

## 第 0 步：定目标函数（先于一切）

- [ ] **当前只做末日幻影**：`分数 = 2000 + 剩余行动值`（帧实证 3834 = 2000+1834）。混沌 / 虚构 / 王棋的口径已知不同但**暂不建模**，别混进来
- [ ] 目标分写下来（例 3900 / 3834）。差多少分 = 差多少 AV = 优化空间
- [ ] 记住敌方扣量是**配额制**（实测 117~119 AV 恒定）：拖时间不会多扣，打太快才会少扣；唯一可压的大块是 boss 第二次正式回合

## 第 1 层：定骨架（产 baseline）

- [ ] 六我方 + 全敌方的 SPD 列全，**含进场条**（翁瓦克 40%、boss 96.5% 都是反解出来的）
- [ ] 目标函数已定，先跑一遍**零拉条、零机制**的纯行动条解 → 这是 baseline，后续所有收益都对着它算差分
- [ ] 验收：敌我格点与实测 AV 逐位吻合，差的每一个都要能解释

## 第 2 层：加拉条

- [ ] 从 `20-action` 把**全部**拉条算子列出来，逐个写清：触发条件 / 拉多少 / 给谁 / 是否占用行动
- [ ] 每一条都要在轴上有落点，并记「被谁提前了几 AV」
- [ ] 验收：实际轴 AV − baseline AV = 各拉条收益之和（对不上说明漏了算子）

## 第 3 层：加机制（这一层会返工，正常）

- [ ] 敌方技能序列：类型先定 —— 老式线性（查表）/ 机制 Boss（事件驱动，无固定表）
- [ ] 机制闸门：力场锁、韧锁、阶段转换、次数盾 —— 逐条写「什么时候解」
- [ ] 资源四账全程记账：SP / 能量 / 笑点 / 隐藏分，**初始值含进战 50% 能量**
- [ ] 重跑：第 2 层的最优动作在这一层可能被判非法，要接受返工
- [ ] 验收：破韧时点、力场解锁时点、被跳过的敌方技能，三个数都要写出来

## 第 4 层：对账与优化

- [ ] 期望 vs 实际逐行对照（轴表必须有这两列）
- [ ] 不确定性分三类记账：① 算得出的（必须钉死）② 没测的（标 🟡 带判别式）③ 真 RNG（受击/暴击）
- [ ] **凹点 ≤ 1**，且每个凹点要写「收益 > 风险」的理由
- [ ] 不符预期时改**第 1 层的输入参数**（速度/进场条/敌方周期），不是硬改轴
