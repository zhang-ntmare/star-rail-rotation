# L0 红线

> 每条都能写出「违反 / 没违反」的判定。写不出判定的，退回 `L1-排轴前清单`。
> 全部来自实际犯过的错，不是理论。

## 1. 数值必须带来源

**判定**：这行数字旁边有没有来源（官方词条 / 实测截图 / 帧号 / 文档路径）？
没有 → 违反。不确定 → 必须标 🟡 并写判别式。

## 2. 禁止用 RNG 项闭合算术账

**判定**：账本里有没有「受击 +X」「暴击」「嘲讽命中」这类随机项，且去掉它就闭合不了？
是 → 违反，账是凑出来的。

> 事故：爻光 164 被拆成「127 + boss 打中你 12.4 + A 25」。真账是 90 + 37.3（秘技）+ 37.3（普攻回能 = 战技档），根本不需要受击。

## 3. 看 HUD 数字前先确认它是什么 UI 元素

**判定**：这个数字的读法有没有被独立证据确认过（锁定信息卡 / 解包字段 / 官方文案）？
只凭「血条旁边那个数」→ 违反。

> 事故：破晓战队的 `x/2`、`x/4` 计数徽章被读成韧条 474/274，韧条结论连错两次。

## 4. 禁止用录像反推代替计算

**判定**：这一动的时点是引擎算出来的，还是从视频里抄的？
视频只能做两件事：**校准未知参数**、**验收结果**。用来决定「下一步做什么动作」→ 违反。

## 5. 一处修正必须全链回扫

**判定**：改了一个结论之后，有没有 grep 全库找它的引用并逐个核对？
改一处就收工 → 违反。

> 事故：SP 台账改了，`§0` 和 `§4` 两份表只改了一份。

## 6. 一份轴只允许一张表

**判定**：这条轴是不是被拆成了多张表（P1 一张 / 循环一张 / 转阶段一张 / P2 一张）？
是 → 违反。**全部并进一张表**，循环用同表内的行标记（`C1`…`C8` / `T1`…`T3` / `P1`…`P6`），不单列小节。

> 理由：分表必然导致"改一处漏三处"。大人翻四张表对不上账，是真实发生过的事。

## 7. 同一份知识只存一份

**判定**：这个结论在库里出现两次以上吗？
是 → 违反，留一份，其余引用。

## 8. 轴表只留正确版

**判定**：轴表里还有划线旧判、`~~xxx~~`、"旧版作废"、"改触发式（日期）"这类修改痕迹吗？
有 → 违反，**整行删掉重写**。

- **轴是产物，要干净**：只写现在该怎么打。错的、旧的、被推翻的，一个字都不留。
- **证据留在别处**：为什么错、错在哪，写进 `70-runs` 的对账记录或 `80-tools` 的复查报告。知识层节点被推翻才用 `status: superseded`（那是给下一个人看的反面证据），**轴表里不承担这个职责**。

## 9. 轴表必须能照着打

**判定**：随便挑一行，能不能只靠这一行知道：谁动、做什么、是不是插队、要不要停下来看什么？
做不到 → 违反。

每行至少含：`#` `时点 AV` `谁` `做什么` `类型（常规 / 插入抢轴 / 观察）` `触发或观察条件` `期望` `实际` `段标记`。
"观察"行必须写明看的是**韧性 / 机制 / 能量** 里的哪一项。

## 10. 同类机制 ≠ 同一参数，必须逐个单位查

**判定**：这个参数是按「三人都是 5，第四个也应该是 5」推出来的，还是**每个单位各有自己的字段/原文**？
靠归纳推的 → 违反。

> 事故：欢愉技被当成统一规格。实际是——回能 `真珠/爻光/欢愉主 5`、**狼尊 0（换隐藏分）**；削韧 `爻光 45 / 欢愉主 20 / 狼尊 10 仅强化版 / 真珠 0（对己方放）`。同一个名字下四套参数。
>
> 查法：数据站逐角色看 `Energy Gen` 与 `Break (In-Game)` 两行；**某行不存在 ≠ 0，要单独确认**（真珠、狼尊非无敌版都没有 Break 字段）。
