# 40 敌方区

**管**：一个怪多少血多少速、技能什么顺序、属于哪类行为模型。
**不管**：我方怎么打它（→ 70）；通用韧性公式（→ 10，这里只记「这只怪实际多少韧」）。

## 敌方节点固定结构

1. 基础属性：HP / DEF / SPD / 韧性 / 各属性抗性
2. 行为模型分类（**先分类再记技能**）
   - **老式线性**：固定轮转表 + 可观测状态分支，破韧不重置索引 → 可查表、可预测
   - **机制 Boss**：事件插入 / 骰子抽选 / 随机属性弹射 → 无固定循环，只能事件驱动建模
3. 技能序列（含每招的受击回能档位：弹射 5 / 轻击群攻 10 / 精英重击 15 / 超重击 20）
4. 阶段与闸门（力场、韧锁、次数盾、转阶段是否吞额外回合）
5. 时序实测（周期、进场条、槽位格点）
6. 待钉 🟡

## 帕姆王（节点一）机制要点 — 2026-11-22 外部攻略印证

| 项 | 内容 | 来源 |
|---|---|---|
| 减伤 | 全阶段 **88%** = P1 **2×44%** / P2 **4×22%**；每消灭 1 个破晓成员剥 1 层 | 4.7 末日满星攻略（多篇一致） |
| 韧条 | **P1 480 / P2 840** —— 与我方实测一致，获第三方独立印证 | 同上 |
| 破晓次数盾 | 每个成员 **16 层**，受击 −1、**欢愉伤害 −2** | 同上 + 游戏内首领特性面板 |
| 破晓力场 | 被召唤时**立即**进【破晓力场】；力场期间首领获得该成员同属性**伤害免疫 + 弱点无效**；**若敌方两动内未击杀，会重新进入力场（盾回满）** | 同上 |
| 破晓退散（退场 ≠ 死亡） | 计数 16 满 → 该成员**下次行动**施放【破晓退散】：解除力场、损失一定生命、挂【失意】（受伤提高+抗性降低）。**退散后小怪仍在场**，要真击杀才触发保姆额外回合；退散后两动内未击杀 → 重新进力场、盾回满 | 三Boss机制详解 §1.4 + 大人实测 |
| 保姆强普来源 | ①累计 **80 笑点**换 1 次；②**每消灭 1 个破晓成员立刻**获得 1 次额外回合（击杀即刻给，不是攒充能） | 同上 |
| 保姆强普效果 | 无视【弱点无效】**强制削韧**（我方实测 100）+ 剥 1 层减伤 | 同上 + 我方实测 |

> **排轴含义**：小怪不是"有余力再清"，是**两动窗口内的硬性 DDL**——超时力场重进，前面削的盾白费。P1 只有 2 个成员（2 层减伤），P2 变 4 个（4 层），所以 P2 的窗口压力是 P1 的两倍。

## 缺口

- **通用敌方属性表**（不带机制的纯数值）：数据源已解决（hsr-trend 逐怪可查，含 SPD/韧性/弱点），**待抓取落表**。
- 「技能序列」与「行动周期」没有分列 —— 这是两件事：什么时候动（速度）、动的时候放什么（序列表）。

## 写入规则

- **不做全图鉴**：只收「当前要打的怪」和「计划要打的怪」。没进过排轴流程的怪不建档 —— 抄来的数值没有验收，建了也是负资产。
- 韧性终值必须写清口径：拆包 `stance_base ÷ 2.5 = 显示韧条`（详见 `10-basics/韧性条口径`）。
- HUD 上的红徽章 `x/2`、`x/4` 是**破晓计数**，不是韧条（L0 红线 3）。
- 每只怪实测后补一行「周期 / 进场条 / 首个动作」，没有这三项不许进引擎。
- 版本变动会让数值作废：节点必须带 `game_ver`，版本更新后重打一次再改。
