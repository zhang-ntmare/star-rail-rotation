# 帕姆王节点一 · 收尾轴（斩杀竞速 → 3929 天花板）

> **一句话**：分数 = 2000 + 剩余 AV，敌方扣量是**配额制**（三局恒定 117~119，与伤害/时长无关）。尾段唯一提分项 = **抢在 boss「扫除」（第二次正式回合，−46 AV）出手前击杀** → 3883 + 46 = **3929 理论天花板**。3900 是"收尾提速砍一次敌方回合"，不是多打伤害。
>
> **手动 3833 为什么输给自动 3883**：大人那局 P2 **弱点全程锁着、没有「蒸汽洗涤」退出 toast**——斩杀窗（窗口 D）压根没开，全程用保姆强化a（~34万/发真伤）在 88% 减伤下磨了 **78 AV**（89→167），敌方把配额回合打满还多出手（总扣 167 ≫ 117~119）。自动局开出了窗口 D、灌了大招，但**收尾仍慢一步，「扫除」还是出手了**（结算 1883 = 已扣 46）→ 3883。所以：**窗口 D 是"不比自动差"的入场券；赶在「扫除」前清场才是 3900+ 的提分项。** 收尾轴 = 两步都要做到。

## 〇、前情红线（打之前先接受这三条）

1. **别再堆伤害**：伤害 ×1.2~×4 引擎扫描，P2 击杀卡在离散平台——瓶颈是**状态减伤（蒸汽洗涤 88%）+ 敌方配额**，不是 DPS。未破状态时 boss 117 秒只掉 1% 血（轮转表 §9.2）。
2. **别再信引擎的 elapsed**：引擎按行动条/DPS 建模，天然算不出配额制计分。它的 3808/3910 不是物理上限。收尾轴按**屏幕信号**打，不按引擎格点打。
3. **转阶段 AV 冻结**：P1→P2 演出 ~15s 全程不扣 AV（三局验证），第二发 99 好活盲盒白赚。**收尾是 P2 段的事，别在 P1 尾段提前攒大招到浪费。**

## 二、四个过程信号（只理这四条，其余敌方动作全是背景板）

1. 🔴 **P2 蒸汽洗涤退出**（HP 92→73 大跳 + toast）——**斩杀窗开的唯一信号**，没看到它之前的大招都算打在减伤上。
2. 🔴 **小怪真杀**（计数满 16 退散后补刀）——保姆白得强普、boss 削韧、狼尊强普独吃三合一。
3. 🔴 **破韧「全力输出」toast**——全队免能量大，排队别乱（真珠 > 欢愉主 > 爻光）。
4. 🔴 **boss「扫除」蓄力横幅**（AV 会掉 −46，具体读数因局而异）——最后通牒，所有大招清空，赶在它出手前击杀。

> P2 的泼脏水 / 无死角洗涤 / 强效肥皂泡 = **免费插入演出，不扣 AV**，看到了不用理，当白嫖输出期。
