# 3900 翻案：不是 DPS，是砍掉 boss「扫除」的 −46 AV

> **认错记录**：大人「我排轴让他手动打 3833，自动 3883」。这是失败。更严重的是我此前把 3900 当成输出密度问题（声称要 7.1 倍、练度不可达、写了一整份"可行性分析"）——**目标函数搞错了**。项目早有正确答案，我没用，还排了不如自动的轴。本文是翻案与纠偏。

## 一、我错在哪

| 我的错误结论 | 事实 |
|---|---|
| 3900 = elapsed100 = P2 只剩 11 AV → 要 7.1 倍输出密度 | 分数 = **2000 + 剩余AV**，剩余AV 由**敌方扣量**决定，不是我方打了多久 |
| P2 慢是因为"等隐藏分120/保姆38AV节流"，调节奏能省 50 AV | 敌方扣量是**配额制/脚本制**：三局（auto 4:27 / 手动 8:35 / weak 8:21）总扣恒定 **117~119**，与伤害、时长、配置几乎零相关。拖时间不多扣，打快了才少扣 |
| 堆练度/堆伤害救不了 → 3900 不可达 | 可达。13金 3967 那局总扣仅 33——**在 boss 把正式回合打完前就杀了**。3900 是收尾提速砍一次敌方回合，不是 DPS |

## 三、敌方扣量结构（docs/data/末日幻影-P22-敌方轮转表 §9.2）

```
总扣 117~119 = boss首动(−31~34，技能随机) + 小怪零头(~26~40)
             + boss第二次正式回合「扫除」(−46) + 尾巴(−4~7)
```

- boss 技能事件恒 **5 次**（P1≈2 / P2≈3），配额制。
- 泼脏水/无死角洗涤/强效肥皂泡 = **免费插入演出，不扣 AV**。
- 转阶段 = 免费（三次验证）。
- **唯一可压缩的大块 = 「扫除」的 −46 AV**（weak 局 f0377-378 横幅实锤，1935→1889）。

## 四、3900 的正确打法

- auto 3883 = 敌方把「扫除」打出来了（扣满 117）。
- **在 boss「扫除」出手前击杀 → 砍掉 −46 → 3883+46 = 3929 理论天花板**。
- 3900（+17）落在 3883 与 3929 之间 → **是"收尾提速到赶在扫除前"的问题，不是多打 17 分伤害**。
- 手法账（见实战轴 §596）：6 金无凹 3904 是标尺，我们 5 金+真珠2魂联动，3900 是保守目标。

## 五、下一步（这次不臆填）

1. **先确认 3833 那局到底为什么比自动低 50 分**——两份录像（auto-test/manual-1x）都是 3883 局，**没有 3833 的录像**。大人 3833 局的敌方扣量应是 2000−1833=167，远超配额 117~119 → 那局**敌方多出手了**，需看那局录像确认是哪几次（大概率「扫除」+额外回合）。**无录像前不推断**。
2. 拿到 3833 局录像后，逐帧读敌方扣 AV 事件，定位多出的 ~50 AV 来自哪个回合。
3. 按实战轴 §斩杀竞速（🔴⚡8）：P2「蒸汽洗涤」被打退 → 全队大招立刻灌，在「扫除」出手前清空 P2 血条。
