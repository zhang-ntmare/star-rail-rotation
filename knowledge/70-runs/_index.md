# 70 产物区

**管**：具体某一次、某一关、某一队打出来的东西 —— 轴、对账、实录、别人的参考轴。
**不管**：可复用的结论。**能从产物里提炼出通用规则的，必须提升到 10/20/30/40/50/60，不能只留在这里。**

这一层对应「L4 原始层」：谁在场谁写，不追求整洁，但**不许被当成结论引用**。

## 轴的强制格式：一张表

**只允许一张表。** 不许拆 P1 / 循环 / 转阶段 / P2 四张，不许另开"详细表"。
循环阶段用**同表内的段标记**（`C1`…`C8` / `T1`…`T3` / `P1`…`P6`）表达，不单列小节。

列固定为九项：

| # | AV | 谁 | 做什么 | 类型 | 触发 / 观察条件 | 期望（算） | 实际（打） | 段 |
|---|---|---|---|---|---|---|---|---|

- **类型**只有四种：`常规` / `插入抢轴` / `观察` / `敌`。
  - `插入抢轴` = 不占行动条、夹在别人回合之间放的（大招、额外回合、欢愉技插队）。这类必须在"做什么"里写清"插在谁的哪一拍之前"。
  - `观察` = 这一行不用操作，但必须**停下来看**。条件里必须点名看的是 **韧性 / 机制 / 能量** 哪一项，以及看到什么值就改做什么。
  - `敌` = 敌方动作行。**敌方必须排进表**，否则看不出谁打断了谁。
- **期望 / 实际**两列必须都有。没这两列就不是成品 —— 无法判断是算错还是打偏。
- 行内不留修改痕迹（划线、作废注）。错了整行重写（L0 红线 8）。

### 观察行的写法（最容易被写虚）

```
| 8 | 58.5 | 爻光 | 开大#1 | 插入抢轴 | boss AOE 落地 → 能量条 180 | 阿哈①提前、狼隐藏分 106 | 贴图 | C1 |
| 9 | 88.4 | —    | 停手看力场 | 观察 | 力场 toast 消失；未消失则狼大顺延 | 力场解除才开狼大 | 贴图 | T2 |
```

第二行不是"等"，是一个**判据**：看到什么才继续。

## 写入规则

- 产物里的每个数值都要标「算的 / 测的 / 抄的」。
- 抄参考轴只能学到**结构与取舍**，时点必须用自己的速度重算（L0 红线 4）。
- 对账发现机制理解错 → 修的是 10/20/30/40 区的结论，不是只改这一份轴。
