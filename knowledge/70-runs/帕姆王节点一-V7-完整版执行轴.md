# 帕姆王节点一 · V7 完整版执行轴

> **自包含**：本文件是**唯一照打文件**，从开局到结算全在一张表里，不用再翻收尾轴或 V7 增量版。两者保留作来源追溯。
>
> **目标函数**：分数 = **2000 + 剩余行动值**。敌方扣量是**配额制**（正常局恒 117~119，与伤害/时长无关；转阶段、插入技免费）。尾段唯一提分项 = **抢在 boss「扫除」（−46 AV）出手前击杀** → 3883 + 46 = **3929 理论天花板**，3900 是保守目标。
>
> **诚实前提**：3833 那局是我排轴让大人手动打的（余 1833），比自动 3883（余 1883）低 50 分；那局**没有录像**。本轴的手法是"基于手法的归因"而非帧证，打一局用结算剩余 AV 反校。

## 〇、开工前必须先接受的三条红线

1. **别再堆伤害**：全局伤害 ×1.2~×4 引擎扫描，P2 击杀卡在离散平台——瓶颈是**状态减伤（蒸汽洗涤 88%）+ 敌方配额**，不是 DPS。未破状态时 boss 长时间只掉极少血。
2. **别信引擎的 elapsed**：引擎按行动条/DPS 建模，天然算不出配额制计分。它的 3808/3910 不是物理上限。**本轴按屏幕信号打，不按引擎格点打。**
3. **转阶段 AV 冻结**：P1→P2 演出期间不扣 AV，第二发 99 好活盲盒白赚。收尾是 P2 段的事，别在 P1 尾段提前把大招打空。
