# 60 队伍区

**管**：这四个人怎么协同 —— 谁先谁后、谁给谁铺、循环骨架怎么转、面板练度是多少。
**不管**：单个角色的技能细节（→ 30）；具体某局的轴（→ 70）。

## 队伍节点固定结构

1. **成员与练度输入**（等级/命座/光锥叠影/遗器/面板实测值）—— 引擎的输入
2. **协同链**：谁给谁什么（拉条 / 回能 / 增伤 / 额外回合 / 底本），画成一条链
3. **参演/出手顺序**：谁先放、为什么（吃满 buff 还是先铺场）
4. **资源收支**：SP / 能量 / 笑点 / 隐藏分 的稳定态
5. **循环骨架**：启动 → 爆发 → 输出 → 维持，每段的目标
6. **该队的方法论沉淀**（可被其他队复用吗？）

## 关键认知（欢愉战舰）

传动链是：**阿哈密度 → 破晓次数盾解除 → 狼尊开大 → 点火 → 爆发**。
不是「谁能量满了就开大」。狼尊开大的真正闸门是**破晓力场**，不是能量。

## 缺口

- 只有一队，无法验证 `20-action` 的算子表是否通用。第二套队（不同命途）是必要验证。
