## 1. 敌方属性数据结构（崩铁助手 sr.appfeng.com）

每个怪物页面提供结构化数据，字段如下：

### 基础属性（STATS）
```
实际值 = 模板基础值 × 本体倍率 × 等级乘区
```
- 字段：生命值、攻击力、防御力、速度、韧性、暴击伤害、效果抵抗
- 有"难度组"概念（不同难度组等级区间与倍率不同）
- 同名敌人按**形态变体**分开收录（弱点/难度组/等级区间可能不同）

示例：卡芙卡 Lv80
```
生命值 1302 ×1 ×148.011 = 192,710
攻击力 18   ×1 ×30.6845 = 552
防御力 210  ×1 ×4.7619  = 1,000
速度   119  ×1 ×1.2      = 143
韧性   450  ×1 ×1        = 450
暴击伤害 20% / 效果抵抗 20%
```

示例：归寂（王棋 Boss）Lv80
```
生命值 14880 ×148.011 = 2,202,404
速度 140 ×1.2 = 168 / 韧性 1200 / 效果抵抗 0% / 状态抵抗 100%
弱点：火、风、虚数；非弱点属性抗性均 20%
```

### 属性抗性（RESISTANCE）
- 逐属性列出（物理/火/冰/雷/风/量子/虚数），弱点属性带标记且抗性为 0
- 部分怪有额外抗性（如卡芙卡雷 40%，其余 20%）

### 负面状态抵抗（DEBUFF RESIST）
- 逐状态列出（如冻结 50%、状态抵抗 100%）

### 技能表（SKILLS）
- 按**阶段**分组（Boss 有阶段 1/2/3）
- 每条技能：名称、类型（单攻/群攻/扩散/弹射/妨害/天赋/蓄力）、属性、完整描述原文
- 例：归寂三阶段 14 个技能，含「埋梗时刻」（蓄力+4 层爆梗）、「爆梗狂欢」（引爆）、「三面化身」（三面机制）、「热场嘉宾」（召唤「粉墨登场」）

## 3. 敌方行动模式：分层模型（老式固定 / 新机制随机）

### 3.1 结论：按敌人类型分层，不是全局一种规则

**三次认知演进（保留痕迹）**：
1. 初版："AI 不可预测、需手动模板" —— 错。
2. 一修："所有敌人全局固定轮转" —— 也错，过度推广。
3. 当前（三修）：**分层**。老式线性怪 = 固定轮转；新机制 Boss = 事件/随机驱动。

**分层依据**：

| 类型 | 代表 | 出招机制 | 依据 | 落地文档 |
|---|---|---|---|---|
| **老式线性怪** | 卡芙卡、宇宙胖、深寒徘徊者、史瓦罗、银枝 | 固定循环表 + 可观测状态分支；破韧不重置索引 | ✅ 玩家回合级实测（卡芙卡 20+ 回合"完美预测下一步"；NGA"全是线性固定流程"） | `08-老式敌方固定轮转表.md` |
| **新机制 Boss** | 归寂（4.4） | 事件插入（粉墨登场/好戏开场）+ 骰子三选一 + 条件触发 + 随机弹射 | ✅ 技能原文（BWIKI/崩铁助手/米游社）；❌ 无固定循环表 | §3.5，待实战录像校准 |

> 区分清楚两层随机：**老式怪"技能选哪个"= 确定**（固定轮转+状态机）；**机制 Boss 的技能含内嵌随机**（骰子/随机属性弹射）。**"打中谁"一律 = 概率**（嘲讽值，见 3.2）。三次误判都源于没把这三层拆开。

### 3.2 老式怪的固定轮转规则（详见 08）

1. **循环索引独立存储**——每敌人 `rotation_index`，行动后 +1 取模；破韧/控制**不重置**（卡芙卡实测）。
2. **确定性分支**——条件是可观测状态（召唤物数量/蓄力是否被破/阶段），不是 AI 偏好，建成状态机。
3. **召唤物独立进轴**——机械手、枪尖、冰锥占独立行动条目。
4. **阶段 = 更高层循环**——银枝按回合数切阶段（3/1/3），与"破韧不重置索引"是两套独立机制。

### 3.3 仍然概率的部分：受击目标与回能

无论老式还是机制 Boss，单体/弹射技能**打中谁**由嘲讽值决定，所以受击回能仍是期望值——这是 0T 凹点的来源。

**嘲讽值（Aggro）公式**（玩家拆包 + 大量实测反推，来源 @666bj / 紫喵 Azunya）：

```
基础嘲讽值（按命途）：
  存护 150 / 毁灭 125 / 同谐·虚无·丰饶 100 / 巡猎·智识 75

受击概率 = 自身嘲讽值 / 全队嘲讽值之和 × 100%       // 与站位无关

伪嘲讽（提高/降低受击概率词条，多个加算）：
  最终嘲讽值 = 基础嘲讽值 × (1 + 增减比例之和)

真嘲讽（火主战技等）：
  强制其他角色嘲讽视为 0 → 嘲讽者受击概率 100%
  （失效条件：效果结束 / 嘲讽者陷入特殊控制）
```

常见受击概率调整：三月七战技 +500%、克拉拉终结技/秘技 +500%、杰帕德行迹 +300%、朗道的选择光锥 +200%、**制胜的瞬间光锥 +200%**（复查修正：旧版记 +100% 是 2023 年解包错误，Fandom Wiki 与米游社 40025446 均已更正）、彦卿天赋 −60%、希儿/素裳/丹恒行迹（血量<50%）−50%。

**弹射目标规则**（Fandom Wiki）：固定从队伍一侧开始依次攻击所有单位，不受嘲讽/目标改变效果影响；若所有单位都打过一轮后仍有剩余次数，则随机选目标。

**锁定**：敌方强力技能前摇锁定某角色，二段攻击优先打锁定目标；可被真嘲讽转移；若锁定目标在进入二段前倒下，则按受击概率随机重选。

### 3.4 建模方案（分层）

| 维度 | 方案 |
|---|---|
| 敌方行动顺序 | 用敌方 SPD 算 AV，与我方统一 AV 时间轴交错 |
| **老式怪技能选择** | **固定轮转表 + 状态机分支**：每怪一张循环表，按行动次数索引取技能；分支条件为可观测状态。逐怪表见 `08` |
| **机制 Boss 技能选择** | **事件序列 + 随机抽样**：按技能原文建事件（插入单位/骰子三选一/条件触发），随机环节做概率分支。归寂是本期目标，待录像校准（见 §3.5） |
| 破韧/控制影响 | 老式怪：延后 AV，**不重置循环索引**（卡芙卡实测）。机制 Boss：可能清除负面/触发阶段，按技能原文处理 |
| 受击目标 | 嘲讽值概率模型；弹射按固定起始侧依次命中，剩余次数随机 |
| 受击回能 | **按攻击强度分档**（弹射每段5 / 轻击群攻10 / 精英重击15 / 超重击蓄力20，见 `02` §2 已定论）× 受击概率 → 期望值 |
| 凹点分析 | 老式怪凹点只来自"打中谁"；机制 Boss 凹点还含骰子结果/随机属性。都输出概率分布与所需凹度 |

> "结果驱动"定位的正确取舍：**老式敌方的"做什么"能精确算准，机制 Boss 的"做什么"部分是随机的，"打中谁"一律算期望**。工具不应把整条轴都假装不确定，也不应把随机环节假装确定。

### 3.5 新机制 Boss：归寂（4.4 周本）——非固定轮转，待录像校准

**已确证事实**（技能原文，BWIKI / 崩铁助手 / 米游社多源一致）：

- **14 个技能是去重总数**，按阶段为 6 / 9 / 10（累计），**不存在公开的出招顺序表**——wiki 与攻略站只给技能表（名称/类型/描述/回能），无顺序字段。
- **「收束命运的博弈」**：掷三个骰子 → **玩家选一个**给全队 → 剩余两个施加给归寂自身（"随机取三个"的真相：骰子随机、玩家选，不是 Boss 随机放技能）。
- **事件插入行动序列**：「热场嘉宾」插入「粉墨登场」召唤喜剧学家（米游社4.7帖：每 58 行动值一次）；「笑话来自地狱」插入「好戏开场」解控+放愿此行终抵毁灭。
- **触发/条件技能**：「爆梗狂欢」在我方施放爆梗时触发；终结技「万法万色，终至成空」需三面都放过才激活；天赋"战技/终结技 44% 固定概率回血"；结界期间我方概率必触发、敌方概率不触发。
- **随机属性弹射**：终结技弹射造成"随机属性伤害""随机敌方单体"。

**结论**：归寂是**状态机 + 骰子随机 + 事件插入 + 概率触发**，不能套用固定轮转表。其出招规律 wiki 拿不到，按计划走**实战录像逐帧记录**路线落地（另立文档，待办）。
