# 02 · 回能与战技点

> 可信度：✅ 高（BWiki 机制页 + 米游社 + 多攻略站一致）
> 来源：BWiki《能量恢复机制解说》、米游社《基础攻略之速度充能dpr》、Reko Wiki
>
> ⚠️ **2026-11-21 复查修正**：原 §2「单体 15 vs 10 有分歧、待实测」已定论——不是分歧，是**按敌人攻击强度分档**（轻击10/重击15/超重击20）。详见 `09-结论严格复查报告.md`。

## 1. 回能五来源

| 来源 | 基础回能 |
|---|---|
| 普攻 | 20 |
| 战技 | 30 |
| 终结技释放后 | 5 |
| 追加攻击 | 10（黑塔/克拉拉为 5；景元神君、青雀不求人不回能） |
| 击杀 | 10（精英/小怪均同；BOSS 破血条转阶段不算击杀） |

### 弹射型战技

回能按初始段数**均分**到每段，段数变化则总回能变化：

- 艾丝妲战技 5 段，每段 30÷5 = 6；1 魂变 6 段 → 6×6 = 36
- 瓦尔特战技 3 段，每段 10；6 魂变 4 段 → 10×4 = 40

### 终结技回能计算

```
实际回能 = 基础回能 × (1 + 能量回复效率)
```

- 能量回复效率为主页面属性（战斗面板显示的是含 100% 基础的总值，注意区分）。
- 能量回复效率影响：行动回能、天赋回能、星魂回能、光锥回能；**对停云的回能不生效**。

## 2. 受击回能（凹点核心）

受击回能取决于**敌方这次攻击的强度档位**，而非笼统的"单体/AOE"。多源一致的完整分档（B站《能量恢复机制解读》24212275、米游社 39617515）：

| 敌方攻击档位 | 我方受击回能 |
|---|---|
| 弹射 | 每段 5 |
| 群攻 / 小怪普攻 / 精英轻击 | 10（每人） |
| 精英重击（如人马射击、践踏） | 15 |
| 精英超重击（蓄力 1 回合，如电锯连砍） | 20 |

> ✅ **复查定论**：旧版记的"单体 15 / 群攻 10，但部分资料记单体 10"并非资料冲突——15 对应**精英重击**、10 对应**轻击/群攻**，是两个不同档位。原"待实测"标记取消。
> 建模取法：敌方技能表需带一个 `受击回能档位` 字段（5/10/15/20），由该技能原文描述判定，不按单体/群攻粗略归类。

受击回能对 0T 竞速至关重要——通过"凹受击"（重置战斗直到特定角色被打到特定次数）来提前充满终结技。

## 3. 战技点（SP）

- 进战初始 3 点，上限 5（部分机制可突破）
- 普攻 +1，战技 −1
- 战技点不足则无法施放战技
- 全队共享，是排轴的核心约束之一

### 建模板
```
sp' = clamp(sp + delta, 0, maxSp)
普攻: delta = +1
战技: 需要 sp >= 1，delta = -1，否则退化为普攻
```

## 4. 对排轴器的意义

- 回能流转决定终结技何时可用 → 终结技不占 AV、可插队 → 必须纳入离散事件模拟
- 受击回能是概率事件，依赖：敌方技能类型 + 打中谁（嘲讽值模型，见 06 号文档）
- SP 收支是行动层之外的第二约束，需在每个行动节点更新

## ⭐ 进战初始能量（2026-11-23 补录——此前整份调研漏了这条通用机制，导致轴的能量账全错底）

- **规则**：挑战类副本（忘却之庭/混沌回忆/末日幻影/虚构叙事等）**进战时我方全体获得能量上限的 50%**；大世界遭遇战进战为 0。
- **来源**：B站《能量恢复机制解读》"在忘却之庭初始自带50%能量" + 3DM 姬子机制攻略"忘却之庭中所有角色入场时都会获得50%的能量"双源；🟡 末日幻影是否 50% 无独立文献，但已被实测闭合坐实（下条）。
- **实测闭合（本队 2026-11-23）**：爻光（180 上限）进战 HUD 显示 **127** = 90（50%）+ 秘技自动战技回能 37.3（30×1.244）= 127.3 截断 → **逐位吻合** ✅。真珠（180→90）、欢愉主（160→80）同规则。
- **秘技自动战技照常回能**：爻光秘技「浮光过隙」进战自动释放的那次免费战技**吃满战技回能 37.3**——这就是 127 ≠ 90 的差值来源。
- **爻光普攻回能 = 战技档 37.3（✅ 2026-11-23 大人实测钉死，此前台账错记 24.9/25）**：爻光「雀翎鸣镝」BWIKI 原文"回能同战技"（30×1.244=37.3）。铁证：@31 A 后**无受击** HUD 显示 **164/180** = 90+37.3+37.3=164.7 截断 → 164，逐位闭合；旧账"+12.4 boss@2 受击 +25(A)"是为凑数发明的假账，作废。**受击是 RNG，凡是靠受击才闭合的能量账一律视为错账**。
- **排轴影响**：真珠开局段不需要艺术壁垒喂能（壁垒 90 的价值在 Q 归零后）；欢愉主实际 2~3 动 1 大（非 3 动）；爻光 @80.4 开大能量前提由合演回能覆盖。详见实战轴 §4.11 ②。
