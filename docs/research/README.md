## 核心结论速览

1. **0T 定义**：社区竞速口径 = 首轮行动波次（首轮 150 AV）内结束战斗；官方"拿星"（2/4/6 轮）属休闲模式，两套目标体系分开建。

2. **引擎要建模四层机制**：行动层（AV/SPD/推拉条）、资源层（SP/回能）、状态层（buff 结算/额外行动）、战斗层（伤害乘区/击破/敌方）。前两层公式确定，后两层强依赖游戏数据。

3. **行动值**：`AV = 10000 / SPD`；混沌回忆首轮 150 AV、之后每轮 100 AV（其余三模式口径不同，见 `01` §2.1）。134 速 = 首轮两动（精确阈值 133.34）；160 速 = 前两轮四动；200 速 = 前两轮五动。

4. **伤害公式**：同类乘区加算、跨乘区乘算；`最终伤害 = 基础伤害 × 暴击期望 × 增伤 × 易伤 × 抗性 × 防御 × 减伤`。

5. **击破公式只有一套**（复查修正）：官方 `基础3767(80级) ×(1+击破特攻)×[(韧性+20)/40]×属性倍率`，GameVika 的 942 记法是同式变形；属性倍率火/物理2、风1.5、雷/冰1、量子/虚数0.5。"两套体系"是旧版把两种记法混搭造成的错觉，已废止。

6. **敌方数据缺口已补上**：`sr.appfeng.com`（崩铁助手）提供结构化敌方属性/抗性/技能/本期深渊精确血量，替代缺失的 StarRailRes 敌方部分。

7. **敌方行为分层建模，不是单一规则**（2026-11-21 三次修订定案）：
   - **老式线性怪**（卡芙卡/宇宙胖/深寒徘徊者/史瓦罗/银枝）= **固定轮转表 + 可观测状态分支**，卡芙卡 20+ 回合实测「以此往复、完美预测下一步、破韧后接着循环走」，NGA「全是线性固定流程」。逐怪表见 `08`。
   - **新机制 Boss**（归寂 4.4）= **事件插入 + 骰子三选一 + 随机属性弹射**，无固定循环，其出招规律 wiki 拿不到，待实战录像校准。
   - 两层都适用的概率：**打中谁**（嘲讽值 = 自身嘲讽 ÷ 全队嘲讽和）。
   - 认知演进：①"AI不可预测"→②"全局固定轮转"→③"分层"。前两次都错，保留修订痕迹。

8. **合规边界**：Dimbreath/StarRailData 已于 2024-10 被 DMCA 下架。本项目不自己解包，只消费社区整理的结构化数据（StarRailRes / 崩铁助手 / 官方 Wiki）。
