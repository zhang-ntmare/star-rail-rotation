# 03 · 伤害公式与乘区

> 可信度：✅ 高（灰机Wiki / HoYoWiki / GameVika 三源一致；GameVika 明确标注"取自官方属性详情"）
> 来源：灰机Wiki《伤害计算公式》、GameVika 伤害计算器、米游社、17173

## 1. 直伤总公式

```
最终伤害 = 基础伤害 × 暴击期望 × 增伤 × 易伤 × 抗性 × 防御 × 减伤
```

### 基础伤害区
```
基础伤害 = 属性值 × (基础倍率 + 倍率修正)
```
- 属性值多数为攻击力，少数技能用生命/防御（如刃、开拓者存护）
- 倍率修正：特定条件下的倍率提升（丹恒对减速目标、克拉拉终结技增益等）
- 多属性组成的技能：各部分**加算**（如开拓者存护终结技 = 攻击部分 + 防御部分）

### 暴击区
```
暴击期望 = 1 + 暴击率 × 暴击伤害
暴击时   = 1 + 暴击伤害
```

### 增伤区（同类加算）
```
伤害加成 = 1 + 增伤A + 增伤B + ...
```
- 属性伤害提高（位面球主属性、行迹）、全增伤、特定条件增伤（如对灼烧目标）均在此区

### 易伤区（同类加算）
```
易伤修正 = 1 + 易伤A + 易伤B + ...
```
- 敌方"受到的伤害提高"类效果（瓦尔特行迹、桑博终结技）

### 防御区
```
防御减免 = (200 + 攻击方等级×10) / [防御力 × (1−减防−无视防御) + (200 + 攻击方等级×10)]
```
- 敌方基础防御 ≈ 200 + 10×敌方等级
- 减防/无视防御加算；敌方防御最低为 0，无法为负

### 抗性区
```
抗性修正 = 1 − 抗性 + 抗性降低 + 抗性穿透
```
- 弱点属性抗性 0，非弱点 20%，部分怪额外 +20%/40%（4.0 后最高基础 80%）
- 抗性范围 −100%（受 200% 伤害）~ 90%（受 10% 伤害）
- 减抗与穿透直接加算、互不稀释，收益线性

### 减伤区（不同来源乘算）
```
减伤修正 = (1−减伤A) × (1−减伤B) × ...
```
- 韧性条存在时敌方有 10% 减伤（隐藏属性，未击破时必定吃到）
- 虚弱类效果也在此区

### 韧性修正
- 未击破：受 90% 伤害（0.9 乘区）
- 已击破：受 100% 伤害

## 2. 乘区加算/乘算规则（建模关键）

| 关系 | 乘区 |
|---|---|
| 同类**加算** | 增伤区内部、易伤区内部、防御降低内部、抗性降低/穿透内部 |
| 跨类**乘算** | 基础/暴击/增伤/易伤/抗性/防御/减伤/韧性之间 |
| 不同来源减伤**乘算** | 减伤区内部 |

> 这个规则直接决定 buff 叠加的建模方式：同类 buff 相加进同一个乘区，不能重复相乘。

## 3. 其他

- **效果命中**：`命中概率 = 基础概率 × (1+效果命中) / (1−效果抵抗)`
- 击破伤害**不适用**本公式（见 04 号文档）
