# 星铁别称 / 外号对照表

> 用途：把玩家口语（「555」「狼专」「风套」「红A」）解析成游戏正式名，供面板导入与排轴输入使用。  
> 基准日：2026-11-21　游戏版本：4.7　来源：萌娘百科《用语与梗》、BWIKI、HoYoWiki、Game8 角色库（Patch 4.7.0）、官网版本更新说明。  
> 标注规则：✅ 多源一致 / 🟡 单源或常识待复核 / ⚠️ 易混淆已纠错。

---

## 一、通用别称规则（术语层）

摘自萌娘百科《崩坏：星穹铁道/用语与梗》，这些是**造词规则**，不是单个别称：

| 玩家说法                | 含义                                      |
| ------------------- | --------------------------------------- |
| **武器**              | 光锥                                      |
| **555**             | 光锥「舞！舞！舞！（同谐）」                          |
| **专武 / o专**         | 专属光锥；`o` 为角色名缩写，如「狼专」= 银狼专武             |
| **0+1 / 6+5**       | 星魂数 + 光锥叠影数；0+1 = 0 魂叠 1 专武，后位为 0 表示无专武 |
| **叠X / 精X / 满叠**    | 光锥叠影 1~5 阶 / 叠 5                        |
| **金 / 紫 / 蓝**       | 5 / 4 / 3 星（角色、光锥、遗器通用）                 |
| **某某2 / 某某4**       | 该遗器套装穿 2 件 / 4 件；「2+2」= 两套二件            |
| **外圈 / 内圈**         | 隧洞遗器 / 位面饰品                             |
| **衣 / 鞋 / 球 / 绳**   | 躯干 / 脚部 / 位面球 / 连结绳                     |
| **暴击衣 / 速度鞋 / 量子球** | 主词条为暴击率 / 速度 / 量子伤害的对应部位                |
| **双暴**              | 暴击率 + 暴击伤害                              |
| **大攻击 / 小攻击**       | 攻击力% / 攻击力（大防御、大生命同理）                   |
| **仓管**              | 机制落后、几乎不用的角色                            |

## 三、光锥别称

| 你给的说法        | 正式名         | 说明                                                     | 可信度 |
| ------------ | ----------- | ------------------------------------------------------ | --- |
| **555**      | **舞！舞！舞！**  | 同谐 · 4 星；终结技后全体拉条（满叠 24%），泛用拉条锥                        | ✅   |
| **狼专**（银狼专武） | **欢迎来到银河城** | 欢愉 · 5 星，**银狼LV.999** 专武；+18% 速度、欢愉伤无视 20% 防、开大给 20 笑点 | ✅   |
| **咕咕嘎嘎**     | **菇菇嘎嘎历险记** | 欢愉 · 4 星，4.0 商店兑换；正式名是「**菇**菇嘎嘎」（蘑菇的菇）                 | ✅   |

> ⚠️ **「狼专」有歧义，务必区分**：
>
> - 若队伍里是**银狼LV.999**（欢愉·虚数，本列表第 1 位）→ 狼专 = 「欢迎来到银河城」✅
> - 若是**老银狼**（银狼，虚无·量子，1.1 实装）→ 另有其专武，勿混用 🟡待核  
>   你的列表同时出现两者语境时，默认按「银狼LV.999」解析。
