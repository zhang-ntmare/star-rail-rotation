## 1. 技能机制与数值

### 1.1 普攻 · 驭风的子弹（110101）
- 类型：单攻 / Normal，风属性；`energy: 20`，削韧 10（BWiki）
- 描述：对敌方单体造成 `布洛妮娅 ATK × 倍率` 的风伤
- 倍率（level 1→10）：50% → 140%（`params` 每级 +10%：`[0.5,0.6,…,1.4]`）
- **排轴含义**：普通产点（SP+1）+ 回能 20；触发天赋"自身下次行动提前"

### 1.2 战技 · 作战再部署（110102）★核心
- 类型：辅助 / BPSkill；`energy: 30`，**消耗 SP 1**
- 描述：解除指定我方单体 1 个负面 → 使该目标**立即行动** → 其造成伤害提高，持续 1 回合。**对自身施放不触发立即行动**。
- 伤害提高倍率（level 1→15）：33% → 82.5%
  - 关键档：Lv10=66%，Lv12=72.6%
  - `params[i][0]` 逐值：0.33, 0.363, 0.396, 0.429, 0.462, 0.495, 0.5363, 0.5775, 0.6188, **0.66**, 0.693, 0.726, 0.759, 0.792, 0.825
  - 持续回合 `params[i][2] = 1`（星魂6 时 +1）
- **排轴含义**：
  1. 「立即行动」= **目标 AV 直接归 0**，等效 100% 行动提前，且**不消耗目标的常规回合** → 目标可多吃一轮 buff（详见 `research/05`）
  2. 增伤 buff 按"目标行动次数"递减；星魂6 延长到 2 回合显著改变覆盖窗口
  3. 尾速配速：布洛妮娅速度需略低于主 C，使"主C行动→鸭战技→主C再动"成立

### 1.3 终结技 · 贝洛伯格进行曲（110103）
- 类型：辅助 / Ultra；`energy: 5`（释放后回能 5），**消耗能量 120**
- 描述：我方全体 ATK 提高 X%，并提高 `布洛妮娅暴伤 × Y% + Z%` 的暴伤，持续 2 回合
- 数值（level 1→15，`params [ATK%, 暴伤系数, 暴伤固定值, 回合]`）：
  - Lv1：`[0.33, 0.12, 0.12, 2]` → ATK+33%，暴伤 +12%布洛妮娅暴伤 +12%
  - Lv10：`[0.55, 0.16, 0.20, 2]` → ATK+55%，暴伤 +16%布洛妮娅暴伤 +20%
  - Lv15：`[0.66, 0.18, 0.24, 2]` → ATK+66%，暴伤 +18%布洛妮娅暴伤 +24%
- **排轴含义**：不占 AV、可插队；增益持续 2 回合（不是 2 轮次），覆盖窗口由队友常规行动数决定

### 1.4 天赋 · 先人一步（110104）
- 类型：强化 / Talent
- 描述：施放普攻后，布洛妮娅**下一次行动提前**
- 行动提前比例（level 1→15）：15% → 37.5%（`params` Lv10=0.30）
  - `params[i][0]`：0.15, 0.165, 0.18, 0.195, 0.21, 0.225, 0.2437, 0.2625, 0.2812, **0.30**, 0.315, 0.33, 0.345, 0.36, 0.375
- **排轴含义**：影响布洛妮娅**自身**轴——普攻轴循环下她会比纯 99 速更快再动，是"高速鸭"轴的基础；提前量作用于自身满行动值（`10000/SPD × 比例`）

### 1.5 秘技 · 在旗帜下（110107）
- 描述：下一次战斗开始时我方全体 ATK+15%，持续 2 回合（`params [0.15, 2]`）
- **排轴含义**：入场 buff，开局即挂，影响首轮爆发窗口

## 4. 数据结构与来源（可机读）

### 4.1 StarRailRes ID 映射
```
角色:  characters.json           key "1101"
技能:  character_skills.json     110101普攻 / 110102战技 / 110103终结技 / 110104天赋 / 110107秘技
星魂:  character_ranks.json      110101~110106
行迹:  character_skill_trees.json 1101001...1101210（文件过大，本次改用 BWIKI 补原文）
```
- `params` 为**分级参数数组**：每个子数组 = 该等级的一组成员值（`desc` 中 `#1[i]`、`#2[f1]` 等占位符按序代入）。
- `max_sp` 字段实为**能量上限**，建模须注意。

### 4.2 来源
- StarRailRes（AGPL-3.0）：`https://github.com/Mar-7th/StarRailRes`，`index_new/cn/` 下的 characters / character_skills / character_ranks JSON（本地快照 `docs/data/starrailres/`）
- BWIKI 布洛妮娅词条：https://wiki.biligame.com/sr/布洛妮娅 （基础属性、速度、行迹原文、技能等级数值）
- 交叉验证：StarRailRes `params` 与 BWIKI 等级数值逐档一致（普攻 50→140%、战技 33→82.5%、天赋 15→37.5%、终结技 Lv10 55%/16%/20% 完全吻合）

## 5. 引擎接入清单（给实现用）

- [ ] 角色属性：基础 SPD 99 + 行迹/装备加成（成长曲线见 `character_promotions.json`）
