## 0. 结论（先看这里，都是引擎跑出来的）

1. **爻光 A/E 回能同档（37.3）**，大人实测 164/164 两边一样 —— 与 BWIKI「回能同战技」一致。
   而且**「缺口 3」是两条线共同的落点**：受击线 `127.3+12.4+37.3 = 177.0`；无受击线 `127.3+37.3+12.4(AOE) = 177.0`。殊途同归，都差 3 点。

2. **爻光 Q#1 可以提前到 @58.5**（boss@58.5 的 AOE 必中全队 → 177+12.4 = 满）。效果：
   - 阿哈时刻 #1 从 @64.1 → **@58.5**，池子 **17 → 62**
   - 狼尊在 @58.5 的隐藏分：**6 → 106**（+40 固定笑点 +15 欢愉技 +20 +20 行迹），@64 时 **21 → 121**
   - 即：**狼尊早就够 60 门槛了，比现轴早 ~30 AV**

3. **但"早够 60"换不来"早开大"** —— 狼尊大的真正闸门**不是能量，是破晓力场**。
   引擎实测：@58.5 就开大 → **3 段强普全撞力场（元素免+韧锁），有效 0 段**，破韧也打不出来（S3 政策）。
   所以狼首 Q 在 S1/S2 两种政策下**都是 @88.4**（力场解除那一刻），大人的 @93 已经在这个闸门后。
   → **「爻光启动超越狼启动」这个命题，卡的不是充能，是破晓盾。**

4. **反过来说：破晓盾的解除速度才是全局节拍器**。盾靠「次数」破（欢愉伤 −2/其他 −1），而**阿哈时刻是次数的主要供给**（全队 4 次欢愉技群攻）。
   → **阿哈时刻越早/越多 → 盾破越早 → 狼大越早 → 点火越早**。这条链是这台机器真正的传动轴，我此前完全没有把它当成可计算项。

5. **真珠点火必须跟在狼尊 Q 之后（硬约束）**：真珠无专武 → 90（进战）+37.3（E）+12.4（AOE）+37.3（E @85.6）= **177.0**，差 3 点满；
   这 3 点只能靠「艺术壁垒」90 回能补 → 而壁垒要求**底本狼尊先开大**。所以顺序被锁死：**狼 Q → 真珠 +90 → 真珠点火**。
   翔鹰 4（风套）再给她自身 25% 提前（−13.4 AV），下一发点火来得更快。

6. **"能放就放"是陷阱（引擎证明）**：贪心政策（S3）在 @58.5 同时交狼大+真珠大 → 120 笑点被 @64 的阿哈时刻吃掉、5 段强普全废 → **有效强普 0、未破韧**。自动档打不高就是这个原因。

## 4. 三个「何时」，判据写死

### 4.1 何时大爻光 → **AOE 一打满就开（@58.5），不要压到 @81**

- 判据：177 + 任何一次受击 ≥3 → 满。boss@58.5 AOE **必中全队**，所以只要第一动做完，她必满。
- 收益：阿哈时刻提前、狼账本提前 30 AV 过门槛、抗穿 20%/3 回合提前盖住整段。
- 代价：额外阿哈时刻会提前吃掉当前笑点池 → 自然阿哈①变薄（池 62 vs 17，净赚）。
- ⚠️ **不要指望"她开大能让狼提前开大"**：狼大的闸门是力场，不是充能（见 4.2）。

### 4.2 何时大狼尊 → **力场解除（@88）那一刻；现在 @93 已经滞后一个格点**

- 判据一（硬）：力场在 = 强普撞「元素免疫 + 弱点无效」，**0 段有效**（S3 实测）。
- 判据二（硬）：**点火靠狼 Q 触发艺术壁垒**，狼 Q 必须在点火前。
- 判据三（账本）：Q 时隐藏分越高强普档越高（60 分 +15%），Q 后清空 → 只在窗口开。
- **可压缩的空间**：力场靠"次数"破 → 阿哈时刻/群攻次数越多破得越早 → **狼 Q 从 @93 前移到 @88** 是白赚的 5 AV；要再往前，必须提高阿哈密度（4.3 的底本切换）。

### 4.3 何时大真珠（点火）→ **≥@128，等破晓清场/保姆剥层，不是能量满就开**

- 判据：能量满 ≠ 该开。点火 = 120 笑点 + 额外回合，**这 120 分会被最近的阿哈时刻吃掉**（S4 实测）。
- 底本给谁：**默认狼尊**（点火后 5 段强普吃满 120 分档位）；**要在"拉阿哈密度"的循环里才给爻光**（网上那套轴的语境是爻光做阿哈发动机，不是狼尊爆发）。

### 4.4 风套 + 艺术壁垒 90 的咬合（循环丝滑的机械原理）

```
狼尊 Q（力场解除后，5 段强普 ×50 削韧）
   └─ 艺术壁垒 → 真珠 +90（177 → 180 封顶）→ 同一拍就能点火
真珠 Q（底本狼尊）
   ├─ 翔鹰4：自身提前 25%（−13.4 AV → 下一动更早）
   ├─ 底本提前 30% + 额外回合（+120 笑点 → 狼 Q 后立刻过档）
   └─ 2 魂：爻光/欢愉主也提前 30% → 爻光下一动更早 → 下一次 Q 更早 → 阿哈更密
```
**这就是"大招拉多动"的机械原理**：真珠一发 Q 同时给三条线加速（自身风套、底本、全体欢愉），而她的能量回补靠狼 Q 的壁垒 → **两人互为发动机**。

## 5. 破韧时机（可算部分 + 待钉部分）

- 韧条 **470**（480 − 开怪量子 −10）
- 狼尊强普 **50/段**：Q 一次 3 段 = **150**
- 保姆强普 **100/发**，充能 80 格/发（🟡 1 笑点 = 1 格）
- 破晓小怪 ×4 被清 → **白送 4 发 = 400 韧**
- **470 − 150 = 320 → 还差 3.2 发保姆强普**；白送那 4 发何时落地 = 小怪清场时点 → **破韧 AV ≈ 小怪清场 AV**
- 引擎按"小怪 @112 清"跑出 **破韧 @112**；轴里写 @145 ⇒ 实操小怪更晚清。**这条必须实测：小怪清场 AV 决定破韧 AV，破韧 AV 决定爆发窗。**
- 加速破韧唯一手段 = **狼尊强普**（50/段，是常规 10 的 5 倍）——所以"破韧要靠狼多动"不是感觉，是数值。
