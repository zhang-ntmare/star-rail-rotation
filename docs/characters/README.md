## 写法规范（新角色照此铺开）

1. **角色卡**：正式名/别称/命途属性/版本/定位/可信度/基准日
2. **本队基准面板**（若在基准队内）：uid 实测的等级、星魂、速度、光锥、遗器
3. **核心资源**：该角色独有的能量/状态机制（如隐藏分、好活、笑点、欢愉度）
4. **技能表**：名称/类型/效果/满级倍率/削韧值，每个关键技能后跟"排轴含义"
5. **行迹 + 星魂**：原文效果 + 排轴含义
6. **专属/秘技/配装**：仓库技、秘技、光锥遗器
7. **数据来源表**：逐条标来源与可信度
8. **待验证**：明确列没有可靠依据的点，不硬编

## 排轴含义的标准落点

写"排轴含义"时，每条机制归到以下 5 类之一（引擎据此建模）：

- **AV 类**：行动提前/推迟、拉条比例、额外回合、行动条插入（阿哈）
- **SP 类**：产点/耗点、盲盒回点、战技点抵扣
- **回能/充能类**：固定回能、隐藏分/笑点等特殊充能、充能效率
- **buff 窗口类**：持续回合数、覆盖/消耗规则、增益延长（续好活）
- **伤害/削韧类**：倍率、乘区归属、削韧值、击破推条
