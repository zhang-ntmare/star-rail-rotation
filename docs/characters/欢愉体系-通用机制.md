# 欢愉体系 · 通用机制（地基文档）

> 本文定义欢愉命途的**体系级通用名词与规则**——笑点、欢愉度、好活当赏、阿哈时刻、欢愉伤害、参演编号。
> 四个角色（狼尊/爻光/欢愉主/真珠）的角色卡只写"各自如何使用这些通用资源"，通用规则以本文为准。
> 可信度：✅ 核心规则来自官方前瞻图文 + BWIKI 技能原文 + 米游社《欢愉队探讨》深度解析，多源交叉一致；⚠️ 少数数值/编号有源间差异已标注。
> 调研基准：2026-11-21（游戏 4.7）

---

## 0. 一句话总览

```
欢愉角色行动 → 产出【笑点】(全队共享)
  → 笑点吸引星神【阿哈】，阿哈作为独立行动条实体按自己的速度跑
  → 轮到阿哈 → 开启【阿哈时刻】→ 全队欢愉角色按【参演编号】依次放【欢愉技】(造成欢愉伤害)
  → 阿哈时刻结束 → 消耗的全部笑点转化为每个欢愉角色的【好活当赏】(持续2回合)
  → 带着好活的角色在之后的常规行动中也能造成欢愉伤害
  → 好活到期前再次攒笑点 → 下一个阿哈时刻 → 循环
```

**核心区分（最容易搞混、也最关键）**：

| 名词 | 显示位置 | 归属 | 用途 | 清零/持续 |
|---|---|---|---|---|
| **笑点** | 战技点上方 | **全队共享** | 阿哈时刻伤害乘区；阿哈时刻结束按量转好活 | 阿哈行动后**清零** |
| **好活当赏** | 角色头像下方 | **每角色独立** | 非阿哈时刻的欢愉伤害乘区；各角色天赋触发条件 | 每份**持续 2 回合**，独立计算 |
| **欢愉度** | 面板进阶属性 | 每角色独立 | 欢愉伤害乘区（类似增伤） | 常驻属性 |
| **增笑** | 隐藏乘区 | 每角色独立 | 欢愉伤害独立乘区（稀有，多在星魂） | 常驻/条件 |

> 原文（BWIKI 爻光天赋内嵌说明）：「好活当赏……将本次阿哈时刻的笑点计入该状态，持续 2 回合。多个好活当赏计入的笑点数**合并计算**，各个好活当赏的持续时间**各自独立计算**。」
> 米游社区分：「天赋带出来的是吃好活（包括绯英 1 魂的欢愉技）；阿哈带出来的欢愉技吃笑点。」

## 1. 笑点（Laugh Points）

- **归属**：全队共享，显示在战技点上方。
- **获取**：
  1. 欢愉角色特定行动后产出（普攻/战技/终结技/欢愉技，各角色机制不同）——最主要来源；
  2. 阿哈行动后按队内欢愉角色数量赠送；
  3. 进战时每有一名欢愉角色获得基础笑点；
  4. 怪物机制 / 深渊环境（混沌紊流等）额外给予。
- **作用**：笑点越多 → 阿哈时刻的欢愉伤害越高；阿哈时刻结束后等量转化为好活当赏。
- **消耗/清零**：阿哈行动开启阿哈时刻时消耗**全部**笑点（清零），重新计数。
- **入战初始**：官方前瞻原文「队伍中编入欢愉角色，战斗开始时立即获得基础笑点，每位欢愉角色自带 20 层好活当赏（持续 2 回合）」。
- **排轴含义**：笑点是"进战→第一个阿哈时刻"的启动资源；之后每个阿哈时刻的笑点量 = 两次阿哈之间全队产出的总和。引擎要把笑点当**全队计数器**，按行动累加、被阿哈清零。

## 2. 阿哈与阿哈时刻

### 2.1 阿哈是独立行动条实体

- 有欢愉角色时，行动条上出现面具【阿哈】；欢愉角色越多、越快，阿哈跑得越快。
- 阿哈行动 = 结算优先级**等同终结技**（在行动条以阿哈头像出现）。
- 多波次战斗中**阿哈的行动值保留**，不因转阶段重跑；阿哈时刻中途转波次，后续回合继续完成未放的欢愉技。

### 2.2 阿哈速度公式

```
阿哈速度 = 80（固定基础）
         + 最快欢愉角色速度/5
         + 第二快/10
         + 第三快/20
         + 最慢/50
```
（来源：米游社官方攻略 73238975《【V4.0攻略】欢愉体系(伤害)介绍》原文——第三项系数 `/20`、第四项 `/50` 均已明确；游民星空早期双欢愉版本只给前两项 `80+0.2×最快+0.1×次快`。🟡 分歧：w12z《欢愉体系进阶认知指南》记第四项为 `/40`（即 0.025），与官方攻略 `/50` 不一致，本文以官方攻略为准，分歧待游戏内实测）

> 早期 4.0 攻略以"阿哈 134 速 = 首轮双动"为阈值，本队四人速度 204/187/175/169 →
> 阿哈速度 ≈ 80 + 204/5 + 187/10 + 175/20 + 169/50 = 80 + 40.8 + 18.7 + 8.75 + 3.38 ≈ **151.6**
> → 阿哈 AV ≈ 10000/151.6 ≈ 66，首轮 150 AV 内可行动 2 次。
> ⚠️ 此为本队实测速度的代入估算；若第四项按 w12z 的 `/40` 记，阿哈 ≈ 152.5，对首轮动数阈值无影响。

### 2.3 阿哈时刻流程

1. 阿哈行动 → 解除我方全体欢愉角色的**控制类负面**（冻结/支配等；傀儡类不可解）；
2. 全队欢愉角色按**参演编号从小到大**依次施放欢愉技；
3. 阿哈时刻持续至本次最后一个欢愉技施放结束；
4. 结束时：消耗的全部笑点 → 转化为每个参演角色的好活当赏（持续 2 回合），笑点计数清零。

- 若无任何可施放欢愉技的角色，阿哈改放【要有笑声】（伤害仍随笑点增长）。
- **参演编号**（越小越先放；欢愉主编号源间有分歧，见下 🟡）：

## 3. 欢愉度（Joy）

- 欢愉角色专属面板属性（类似增伤乘区），越高 → 欢愉伤害越高。
- **来源**：角色特定属性按行迹转化 + 行迹直接加成 + 部分技能/秘技。
  - 爻光：行迹「开屏有礼」——速度 ≥120 时 +30%，每超 1 点 +1%，最多计入 200 点超出速度（→ 320 速吃满 230%）；
  - 狼尊：速度 ≥160 时 +50%，每超 1 点 +2%，最多计入 100 点（→ 260 速吃满 250%）；
  - 真珠：防御 ≥2400 时 +32%，每超 100 防 +3%，**最多计入 3600 点超出的防御力（→ 6000 防封顶，140%）**；
  - 欢愉主：攻击 >1000 部分每 200 点 +10%，上限 60%（局内 2200 攻吃满）。
- **排轴含义**：欢愉度是**常驻面板**，进排轴前从面板直接读；但"转模属性"（速度/防御/攻击）会随战斗内 buff 变化，若引擎要算动态欢愉度需按当前属性重算转模。

## 4. 好活当赏（Good Show / 好活）

### 4.1 通用规则（关键）

- **获取**：
  1. 进战时每位欢愉角色获得 **20 点、持续 2 回合**的初始好活；
  2. 每个阿哈时刻结束时，按本次消耗笑点数等量给每个参演角色好活；
  3. 部分角色天赋/行迹额外给予（如欢愉主战技 +20、真珠多种途径）；
  4. 每次获得的好活**独立计持续回合**（2 回合），到点各自失效；多份好活在结算时**笑点数合并计算**。
- **持续**：**2 回合**（基础规则，官方前瞻/BWIKI/米游社三方一致）。
- **作用（通用）**：好活是"非阿哈时刻内造成欢愉伤害"的笑点乘区来源；各角色天赋基于好活点数解锁不同效果（见各角色卡）。
- ⭐ **实机原文补充（2026-11-22 大人截图·爻光增益栏）**：「爻光特有【好活当赏】时，我方目标施放攻击后触发【大吉大利】：对随机 1 个目标额外造成 1 次少量对应属性欢愉伤害；本次攻击若消耗战技点，该效果额外触发 1 次；不视为 1 次攻击」→ 好活当赏持有者**每承受我方一次攻击就追加一次小欢愉伤害（E 类耗 SP 攻击双倍）**。引擎要建"我方攻击结算 → 好活持有者追加段"事件；这也解释了为何"有 SP 就 E"收益高。
- **续期（通用 + 角色专属）**：
  - 通用：进入战斗自带 + 每次阿哈时刻后刷新一轮好活；
  - **狼尊 2 魂**：进入无敌玩家状态时「使自身所有增益效果延长 1 回合」→ 好活属于"自身增益"，被 +1；
  - **狼尊本体·强普清场**：每回合首次「使自身所有增益效果延长 1 回合」；
  - **爻光·额外能力3「鸿运鳞集」**：「爻光获得好活当赏时，使其持续时间增加一回合」——⚠️ 2026-11-21 修正：原文主语是**爻光自身**，只延长**爻光自己那份**好活（2→3 回合），**不能给狼尊/队友续好活**。旧文档写"把全队好活 2→3 回合"是错的，排轴时不可用来维持狼尊强普形态；
  - ⚠️ 注意：某些攻略写"爻光终结技延长好活 1 回合"，但 BWIKI 终结技原文只写"额外回合不消耗回合数/不消耗笑点"，**真正的续期依据是行迹「鸿运鳞集」，且仅对爻光自己生效**——已厘清，别记错。

### 4.2 好活 = 这队排轴的命门

- 好活只持续 2 回合、多份独立衰减 → 可能出现"上秒 150 好活、下回合归零"的断档；
- 狼尊强普要"带好活"才是欢愉伤害形态 → 好活断档 = 输出形态掉档；
- **狼尊好活只能靠狼尊自己的两条路径续**：2 魂开大 + 本体强普清场（都是"自身所有增益 +1 回合"）。⚠️ 2026-11-21 修正：爻光「鸿运鳞集」只延长爻光**自己**的好活，**不适用狼尊**——旧文档把"爻光行迹 +1"算进狼尊续期链是错的。
- 另一个维持途径是**阿哈时刻结束后重新发放**等量好活（全队参演角色都拿新的 2 回合份）。
- **排轴含义**：引擎要把"每个角色的好活"建模成**带到期回合的栈**（每份 = {笑点数, 剩余回合}），结算时合并笑点、到点各自移除；"续 1 回合"= 对栈内所有份 +1 剩余回合。

## 5. 欢愉伤害公式（本体系伤害计算的权威式）

来源：米游社《欢愉队探讨》导论（sr/article/75501126）、17173 转载计算实例、NGA 玩家整理，三源一致。

```
最终欢愉伤害 = 基础值 × 欢愉倍率
             × (1 + 欢愉度)
             × 笑点/好活乘区
             × 双爆区
             × (1 + 增笑)
             × 防御区 × 抗性区 × 易伤区
             × 免伤区(含韧性减伤) × 其余乘区 × 真伤区
```

| 乘区 | 定义 |
|---|---|
| 基础值 | **仅随角色等级变化，80 级 = 7535.107**，等于（超）击破单位削韧值基础 **376.75 的 20 倍**（米游社《欢愉队探讨》导论原文逐字："80 级角色是 7535.1，是（超）击破单位削韧值的基础数值 376.75 的 20 倍"）。⚠️ 2026-11-21 二次复查：11-21 曾误删此等式（误以为击破基础只有 3767）——击破基数实有单位变更：旧制 3767，削韧值改以 10 点为单位后约 376.7/376.755，7535.107÷20=376.755 正好对上，等式成立，已恢复 |
| 欢愉倍率 | 写在角色技能描述里（如爻光欢愉技 100% 群攻 + 20%×5 弹射） |
| 欢愉度 | 1 + 欢愉度（面板读取，常驻） |
| **笑点/好活乘区** | **1 + 5×笑点/(240+笑点)**（阿哈时刻用笑点，常规行动用好活） |
| 双爆区 | 期望 = 1 + 暴击率×暴击伤害；单段暴击 = 1+暴击伤害 |
| 增笑 | 独立乘区（1+增笑%），目前仅爻光 6 魂（25%）、狼尊 6 魂（强普期欢愉伤增笑 50%）、真珠 2 魂（15%）等。⚠️ 2026-11-21 修正：原写"狼尊 4 魂增笑 50%"与角色卡自相矛盾——狼尊 4 魂实为"欢愉技额外计入 5 倍笑点"，增笑 50% 属 6 魂 |
| 防御区 | (200+100×攻击方等级) / [(1−无视防御−减防)×(200+100×敌方等级) + (200+100×攻击方等级)] |
| 抗性区 | 1 + 抗穿 + 减抗 − 抗提（狼尊 6 魂可全抗性降至 0） |
| 易伤区 | 1 + Σ易伤（"受到伤害提高"，限定"欢愉伤"的只对欢愉伤生效） |
| 免伤区 | 各免伤乘算；未破韧 10% 韧性减伤属此区 |

**关键特性**：
- 欢愉伤害**不吃攻击力、生命、常规增伤（造成伤害提高）**——堆攻击对欢愉技无用；
- **吃双暴、抗穿、减防、易伤、真伤**；易伤/抗穿等"外部环境"仍有效；
- 因**没有增伤区，"造成的伤害降低"类效果（异相仲裁桎梏、金人虚弱）不影响欢愉伤害**；
- 欢愉伤害与阿哈时刻**无必然绑定**——任何时候带好活/笑点打出的"欢愉伤害"类型技能都按此式算，阿哈时刻只是"触发全队欢愉技 + 提供笑点乘区"的事件。
