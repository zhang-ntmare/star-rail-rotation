## A. 三个查证结果（全部多源钉死）

### A1. 「阿哈帮大忙了 Lv.3」= 贪饕愿力增益（官方原文，非关卡机制）

出处：4.6/4.7 官方「镇伏『贪饕』，汇聚愿力」系统 + 4.7 版本更新说明。全服愿力汇聚等级 = 增益等级，**在一切贪饕侵蚀关卡常驻生效**（本期末日三节点污染等级 3 全覆盖）。

| 等级 | 我方全体增益 |
|---|---|
| Lv.1 | 攻击力 +150 / 防御力 +120 / 生命上限 +300 / 暴击伤害 +15% |
| **Lv.3** | **攻击力 +300 / 防御力 +240 / 生命上限 +600 / 速度 +12 / 暴击伤害 +30%** |

- ⚠️ **引擎影响**：SPD +12 直接改行动轴（狼尊 204→216、爻光 187→199、真珠 175→187、欢愉主 169→181）——所有 AV 计算必须把这个增益算进速度面板，否则整条轴错位。此前排轴问答清单的 AV 推演全部要按 +12 重算。
- ⚠️ **建模修正**：我们此前把「贪饕」只当 debuff 层建模，漏了这层我方增益。贪饕系统 = debuff（污染）+ 我方愿力增益 + 关卡效果三层。
- 关卡效果（本期官方原文，此前未录）：坚防守备 = 首领幻影受伤 **降低 50%**、弱点击破后行动额外延后、**受到伤害提高 100%**（破韧后爆发窗口的又一层放大）；贪饕生命值 +30%（小怪：+943,703 / +798,518）。
- 参考分（攻略图）：节点一 Buff1 满星参考 3650-3750，实录 3904-3984 为超参考线的高配。

### A2. 「附加伤害」词条（官方战斗名词，B站细节攻略 + 官方名词表）

- 定义：使受击者**额外受到 1 次伤害**。规则：**不视为 1 次攻击**（不触发受击类效果）、**不回能量**、**可以暴击**、**无法削韧**；触发时点在主体伤害最后一段结束之后（吃得到击中前/击中时 buff，吃不到击中后）。
- 增伤规则：不吃"普攻/战技/终结技"类条件增伤；**吃面板全局增伤与对应属性增伤**。
- 视频三（冷冰冰的呆头鹅，0魂狼 8金 3910 分）的流派：**凹狼尊盲盒「超大剑」**（对血最多敌人追加一段真实伤害，属附加伤害类）——0 魂狼伤害缺口靠附加真伤段补，所以词条/触发频率优先。画面上的 真伤 24255 即这一段。
- 引擎落点：附加伤害作为独立伤害段建模（可暴击、不回能、不削韧、不吃条件增伤）。

### A3. 「渲染理性，解构欢愉」= 破晓战队【破晓力场】的状态表现名（🟡名称映射待实机逐帧复核）

- 官方关卡效果原文（多源一致）：【破晓战队】被召唤时立即施放【破晓意志】进入【破晓力场】；力场期间首领幻影获得**与该成员同属性的【伤害免疫】**+**【弱点无效】**。
- 叠加关卡词条：**不动如山**（退出力场所需攻击次数提高）+ **坚不可摧**（力场中受伤大幅降低）。
- 视频一 f0100 的 ×4 连 toast = 四名破晓战队成员依次进入力场（阶段二 4 只）。效果数值已齐（= 官方力场规则），只是"toast 文字 ↔ 状态名"的映射未在拆包/攻略找到书面确认。

### A4. 附带收获：星神★阿哈（虚照）机制全表（为大人抽卡后准备）

- **仓库技（不上场也生效）**：阿哈时刻基础速度 80 → 阿哈自身基础速度（00 阿哈 = 94，专武更高）。⚠️ 我们通用机制文档的阿哈速度公式 `80+…` 是无阿哈角色时的公式，抽到虚照后**底数替换**。

## B. 狼尊欢愉队四问终答（认知自检）

### B1. 真珠大招给谁收益最大？——决策树

点火（美学底本+2魂额外回合）本质是**把 120 笑点和一次额外回合塞给账本最划算的人**：

1. **默认给狼尊**（账本 X 满足下表时）：2 魂额外回合 = 60 好活 + 120 笑点；120 恰好 = 2 魂"每 +120 隐藏分"的一档阈值 → 天生联动。
2. **狼尊账本不达标或不在爆发窗口** → 点火改给**爻光/欢愉主**转轴：真珠照样回 90 能（艺术壁垒认"底本为欢愉角色"不认人）、全队被拉条（非底本也拉）、爻光/欢愉主开大反哺循环。
3. **X ≥ 300 时给狼尊是浪费**（溢出跨不出新档）→ 转给别人。

**狼尊点火账本（开大耗 60，初始 = X+60；2 魂"每使隐藏分提高 120 点（含初始）→ +1 额外回合"）：**

| 点火前隐藏分 X | 初始（耗60后） | 实测档位 | 强普伤害档（每60+15%，独立乘区） | 判定 |
|---|---|---|---|---|
| X < 60 | <120 | 1 档（进场保底） | 低 | 勉强可点 |
| 60 ≤ X < 180 | 120~240 | 1 档 | 2~4 层 | 可点 |
| X ≥ 180 | ≥240 | 1 档起步 | 5 层（120分满） | 账本越厚强普越痛 |

✅ **实机终裁（2026-11-22 大人实测）**：点火 X=180（开大前显示 300=溢出上限）→ 开大 → **2 魂只给 1 个额外回合 + 真珠额外回合 1 个**。所以"含初始"的正确读法 = **进场（含初始）保底 1 档**，不是 floor(初始/120)；无敌玩家期间每累计 +120 隐藏分 → 再 +1 档（欢愉主大招垫在点火前给狼尊补隐藏分 = 在无敌玩家内跨档，这就是萧璿"补隐藏分再开"的原理）。点火的核心价值 = 抬**强普伤害档**（60 分一档 15%，120 分满 2 层）+ 保证 ≥60 进场拿保底档。

🟡 无敌玩家内新增隐藏分的跨档规则（累计 120 跨档 or 每 120 一跳）再要一个数据点可钉死；引擎按"保底 1 档 + 期间累计/120"先行。

### B2. 爻光什么时候开大收益大？

三条件叠加时开，优先级从高到低：

1. **全队笑点峰值后**：1 魂开大产额外阿哈（≈40 笑点），笑点越多收益越大（笑点乘区 1+5×笑点/(240+笑点) 是全队共享的）。
2. **真珠能量缺口时**：+90 能 = 真珠 180 上限的一半，直接决定下一发点火时点。
3. **末法余烬激活窗口**：破晓被击破 → 终结技激活，爻光不用攒满 180 跟着击破走（实录里"一动开大"的解释）。
- 配装加持：翔鹰4（开大后自身行动提前 25%）+ 翁瓦克2 → 开大即自拉条，下一轮还能再开大 = 每 2 轮 2 次 +90 充真珠。大人爻光现带菇菇R5，收益结构不同但链序不变。

### B3. 狼尊什么时候开大收益大？

1. **开局不等点火**：99 好活秘技 + 进战 20 + 首轮笑点攒到隐藏分 60 就开（悲情ya ~20 秒开大实证）——点火留作二段充能。
2. **账本优先**：永远在 X 能跨出新档时开（X≥0 开大后初始 60 保底 1 档；点火后再开争取 180+）。
3. **峰值窗口开**：保姆已剥减伤层 + 破晓力场破除 + 末法余烬激活 → 同一套强普从 ≈54 万跳到 ≈237 万（12 金实录单段），**伤害差全部来自窗口叠加**，宁可屯 1-2 动等窗口。
4. **强普打完立刻接大**：2 魂退出清空隐藏分 → 第二轮账本从 0 重来，晚开 = 档位天花板更低。

### B4. 如何保留好活？

好活当赏 = 非阿哈时刻欢愉伤害的唯一燃料（阿哈时刻不用），规则：持续 2 回合、每份独立计回合、多份合并计算。**"保留"的本质是控发放时点**：

1. 进战自带 20 点（2 回合）——从开战就开始计时，所以**首轮别拖**，尽快打出去或续上。
2. 阿哈时刻结束按消耗笑点等量发放——发放瞬间开始计 2 回合 → **让发放贴近下一次非阿哈欢愉输出窗口**（狼尊强普窗口），别在爆发前 2 回合以上就发。
3. 续期手段：狼尊 2 魂开大 = 自身全部增益 +1 回合（续好活）；狼尊本体强普清场每回合首次全部增益 +1——**强普清场尽量留给好活快到期的回合**。
4. 爻光的续法是额外能力 3「鸿运鳞集」（好活持续 +1 回合），不是终结技（BWIKI 原文，勿记错）。

## C. 排轴总算法（v0.3 引擎骨架 + 人工排轴流程）

### C1. 输入层（缺一轴就错）

1. 角色面板（Mihomo UID 导入，已通）+ **行迹转模动态叠加**（欢愉度面板不含行迹转模、狼尊双爆靠隐藏分）。
2. **贪饕愿力增益 Lv.3**：全队 SPD +12、暴伤 +30% 等直接进面板。
3. 环境三选一（欢愉队锁「魔法时间」：4 欢愉 → 全队欢愉度 +60%）+ 末法余烬（战技伤 +25%/欢愉伤 +15%、破韧激活终结技）。
4. 敌方实体：帕姆王 P1/P2 双血条（42,587,598）、SPD 177、韧性 1200、破晓战队（16 次数盾/力场）、合金保姆（我方实体）。

### C2. 初始化（战前固定脚本）

```
秘技顺序（⚠️ 开怪者二选一：怪味豆99盲盒=狼尊开怪限定 vs 底本=爻光开怪，互斥，见实战轴 §3）：
默认方案A（狼尊开怪）：欢愉主 → 爻光 → 真珠(底本) → 狼尊(召怪味豆) → 狼尊触发战斗 → 底本落在狼尊
进战状态：全队好活20(2回合) / 笑点0 / 保姆0充能 / 狼尊隐藏分0(吃等量笑点)
```

### C3. 主循环（每个 AV 刻，事件驱动）

```
① 找下一个行动者：min(剩余AV)，实体池 = 4角色 + 阿哈实体 + 合金保姆(我方)
② 执行动作（按 A/E 原则与下述判定函数选招）
③ 事件结算链（顺序固定）：
   a. 削韧/伤害 → 次数盾计数（欢愉伤 -2 / 其他 -1）
   b. 笑点变动 → 狼尊隐藏分同步 + 保姆充能条 (80/格)
   c. 破晓死亡 → 保姆 +1 强普额外回合
   d. 保姆闪充满 → 插入强普（剥 1 层 88% 减伤 + 100 韧性）
   e. 破韧 → 解控 + 全队激活终结技（免能量立即可放，开完能量归 0）+ boss 行动延后 + 受伤 +100%（坚防守备）
      ⚠️ 破晓小怪力场期间韧性锁 160 不削；boss 本体韧条 480 可正常削
   f. 阿哈笑点达标 → 阿哈时刻（参演编号：真珠104/爻光116/欢愉主120/狼尊999）
④ 资源账推进：SP / 能量 / 好活栈(-1回合/行动) / 阿哈速度条
⑤ 循环至目标达成（分数≥满星线 或 AV 耗尽）
```

### C4. 动作判定函数（引擎可实现的 6+2 条）

| 判定 | 规则 |

### C5. 输出与校准

## D. 诚实边界

- ✅ 已实机钉死（2026-11-22 大人九连测）：末法余烬"激活"= 免能量立即可放 + 开完能量归 0 + 常驻到施放为止（一次性消耗）；**狼尊吃激活**（按最低档 60 隐藏分激活，所有特殊能量角色都吃）；2 魂"含初始"= 进场保底 1 档（见 B1 账本修正）。
