## 2. 谁开怪？——✅ 爻光开怪吃真珠底本（实录修正，原"真珠首动"说法作废）

大世界**四人秘技全放（4 点够），最后切到爻光触发战斗**——爻光成为【美学底本】持有者。为什么是爻光（多源交叉：BWIKI 原文 + 璐洛洛真珠攻略 + hngameguide + 52xz + 绯绯狐 8金0T 实录全部一致）：

1. **艺术壁垒 90 能量，越早触发越好**：进战后底本若为欢愉角色，其下一次终结技给真珠**固定回 90 能量**（=180 上限的一半）。爻光充能绳 124.4% + 高频大（1 魂额外阿哈时刻），开大时点最确定；狼尊开大受隐藏分 60 门槛限制、时点不定。
2. **实录实证**：绯绯狐视频里爻光进场第一动后 ~24 秒内就开大（第一波刚开始）→ 真珠立即吃 90 能量 → **赶在真珠 2 充能强化普攻打完之前把能量充满**，强普自带的回 30 能不被浪费。
3. **强化普攻伤害按底本属性计算**：真珠【深度学习】的强化普攻（冰伤 + 30%/60% 欢愉伤）使用底本的属性值——爻光攻击面板全队仅次于狼尊，且她的物理属性补真珠的冰盲区。
4. **代价 = 0**：底本转移只要求"触发战斗时操作角色是爻光"，四人秘技照放不误（52xz 提到银狼队舍弃狼尊秘技，本队无此约束——狼尊秘技进战波次盲盒照生效）。

- **【秘技底本】≠【终结技底本】，两个独立状态**：终结技开大时仍然手选狼尊（§8 不变）。秘技底本只在真珠第一次开大前起作用（艺术壁垒触发后被终结技底本刷新）。

## 4. 凹受击？——本队没有嘲讽差，凹受击靠"等 boss 重击 + 生存位兜底"

- **嘲讽值查实（2026-11-21，starrailstation 火花/爻光均 100）**：欢愉命途嘲讽 = 100。四人全欢愉 → 受击概率各 25%，**站位/角色选择都不改变受击分布**。没有"凹打爻光"的常规手段。
- 凹受击的真实窗口来自 **boss 技能形态**（受击回能档位，拆包 `sp_hit_base`）：
  - 帕姆王：灵魂修正剪/无死角洗涤/肥皂泡 10（轻击）、大扫除 15（重击）→ 全体技（洗涤/肥皂泡/大扫除）全队都回；
  - 死龙：厚土安葬**全体平均分摊** → 全队受击回能最匀的一关；
  - 银枝【盾之奉还】：命令盾雕塑**嘲讽对位我方角色** → 被点名者挨打回能暴涨，这是全游戏少有的"定向凹受击"窗口，想让爻光充能就把她排到对位。
- 凹受击的目标读者 = **爻光（180 能，开大驱动额外阿哈）** 与真珠（180 能）。狼尊无能量条（见 §10）。
- 🟡 缺口：我方角色受击回能的精确公式值（受击系数×档位）未落 02 号文档，排轴暂按档位近似。

## 5. 狼尊弹射？——100 段均分到存活目标，先清小怪再打 boss

- 强普 240% 攻击力总伤均分 100 段弹射；**段数按存活目标均分**（按 BWIKI"均分"字面理解）：单体 boss = 100 段全吃；帕姆王 + 3 小怪 = 每目标 ~25 段。
- 最后一击 100% 攻击力由敌全体均分（独立一段）。
- 削韧：强普总计削韧 50，也随段数分散 → 单体时 50 全进 boss 韧性条（帕姆王 1200 → 24 次强普打空，需配合击破效率 buff）。
- **排轴含义**：破晓战队三小怪在场时 boss 有【伤害免疫+弱点无效】（破晓力场）→ **弹射打小怪不是浪费，是必要的破盾路径**（16 层次数盾、欢愉伤一次扣 2 层）；清完再打 boss。
- 🟡 缺口："均分"是严格均等还是随机分配，实机确认；段数溢出目标死亡时是否重分配（配合清场续好活路径 A）。

## 6. 续好活？——三个来源两个续法，狼尊栈只能自己续

- **来源**：①进战每人 20 点/2回合；②阿哈时刻结束按消耗笑点等量发放（全员）；③欢愉主战技 +20（自己）、真珠秘技 +20（抵挡池，另一套）。狼尊波次盲盒（99 好活）由**我方欢愉技施放**触发——爻光战技✅、真珠战技❌、欢愉主✅（萧璿解说坐实）。
- **合并规则**：多份好活笑点合并计算、持续各 2 回合独立衰减。
- **续期**：狼尊只能靠 **2 魂开大** 或 **强普清场**（都是"自身全部增益 +1 回合"）；爻光「鸿运鳞集」只续她自己；阿哈时刻重发是全队兜底。
- **断档判定**：强普期盯狼尊栈最临近到期的一份；好活衰减时机（回合开始/结束扣）未定 → 引擎按保守（回合开始扣）建模。

## 8. 真珠 buff 给谁？——终结技底本永远选狼尊；秘技底本给爻光（见 §2）

- **终结技【美学底本】= 狼尊**：4 欢愉满档 → 行动提前 30% + 额外回合（2 魂：额外回合给 60 好活 + **120 笑点**，且除真珠和底本外其他人也拉条）。
- 天赋/欢愉技 +40% 欢愉伤：我方全体下次攻击触发（阿哈时刻 104 编号先放 → 后三人吃满）。
- 抵挡池好活：全队共享池（1 点=200 抵御、上限 50 点、持有时全队效果抵抗 +50%）。
- **艺术壁垒（璐洛洛攻略补全的节奏规则）**：底本为欢愉角色 → 其下次终结技给真珠回 90 能量；**该效果无法叠加、真珠每放一次大只吃一次**——底本连续两次开大，第二次不回，要等真珠自己开过大大之后才刷新。所以真珠的开大循环和"底本什么时候开大"是绑死的：轴上要让**底本开大 → 真珠回 90 → 真珠开大 → 刷新 → 底本再开大**交替咬合，不能让底本连开两次中间真珠没动。
- 代练通文章补充的**首轮点火原则**：第一发终结技底本**不要**给狼尊（他开局没隐藏分，额外回合浪费）——先给爻光/欢愉主这类能量快充好的队友把轴转起来，等狼尊隐藏分窗口到了再标狼尊，额外回合才是爆发期。（与 §10 开大链序"真珠点火→狼尊"不冲突：那是隐藏分已够之后的点火。）

## 11. 伤害估算？——框架已立，量级粗估一轮爆发 ≈ 400~500 万（误差 ±50%+）

按欢愉伤害公式（通用机制 §5）代入本队（**2026-11-22 真实面板已拉取**，见 [`../data/欢愉战舰-面板实测-20261122.md`](../data/欢愉战舰-面板实测-20261122.md)）：

- 欢愉度：面板 18% + 行迹转模 138%（204速）+ 真珠1魂 60% + 魔法时间 60% + 欢愉主秘技 20% + 爻光结界 ~53%（爻光实战欢愉度267%×20%）≈ **349% → (1+3.49) ≈ 4.49**。⚠️ Mihomo 面板欢愉度不含行迹大转模，引擎须局内动态叠加
- 笑点/好活乘区：100 点好活 ≈ **2.47**；阿哈时刻 120 笑点 ≈ **2.67**
- 双爆区：满暴 + 爆伤 ≈221%（面板107.4+朋克52+隐藏分转化~62）→ 期望 ≈ **3.21**（阿哈时刻前隐藏分未满时更低）｜增笑（真珠2魂）×1.15
