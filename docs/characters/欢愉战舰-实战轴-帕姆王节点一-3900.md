### 6.1 名词解释：2 魂"含初始"是什么意思

狼尊 2 魂原文：**无敌玩家期间，每使【隐藏分】提高 120 点（含初始）→ +1 额外回合 + 1 次强普恢复**。

- 账本示例（点火 120、开大前账本 X）：初始 = X + 120 − 60 = X + 60。

  - X = 300 → 初始 360 → 3 档，但终结技总上限 300 → 有溢出浪费
- **为什么这条语义关键**：如果实际规则"不含初始"（只有进场后新涨的才算），同样 X=180 进场是 0 档，点火收益直接少一档，且最优顺序反转（点火放开大之后）。**实机验证**：点火→开大后看狼尊头上的额外回合图标——进场就有 = 含初始，进场没有 = 不含。
