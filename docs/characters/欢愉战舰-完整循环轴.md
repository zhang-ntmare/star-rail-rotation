## 1. 启动层：堆笑点 → 阿哈时刻（目标：喂饱狼尊隐藏分开大）

笑点是全队共享计数器，来源是四人行动。**关键产笑点动作**：

| 角色 | 产笑点动作 | 笑点量 |
|---|---|---|
| 爻光 | 战技展开结界，结界内每次普攻/战技 | +3/次（🟡 结界加成值有 15/20% 差异） |
| 爻光 | 终结技「霓裳铁羽」 | +5，并立即触发**额外阿哈时刻**（固定 20 笑点，1魂→40，不消耗现有笑点） |
| 欢愉主 | 天赋「英雄一笑」攻击后 | +3/次（多源一致） |
| 狼尊 | 战技「Shoot属性大爆发」 | +5（=+5 隐藏分） |
| 狼尊 | 欢愉技·常态 | +15 隐藏分（不经笑点） |

**阿哈时刻（自动事件，不占我方 AV）**：
1. 解控 → 2. 按参演编号放欢愉技：真珠(104) → 爻光(116) → 欢愉主(120 ✅) → 狼尊(999)
   - 真珠欢愉技先挂"下次攻击 +40% 欢愉伤"→ 后面三人吃满；
   - 狼尊最后放，吃满前面所有增伤；
3. 结束：消耗的全部笑点 → 每人一份好活（持续 2 回合，独立计），笑点清零。

> **排轴要点**：狼尊行迹「真结局解锁条件」——欢愉技计入笑点 ≥20 额外 +20 隐藏分、≥40 再 +20。所以**爻光 1 魂把额外阿哈固定 40 笑点**正好让狼尊这一下吃满 +40 隐藏分。

> 真珠给 120 笑点 → 狼尊 +120 隐藏分 → 加上开大时的隐藏分 → 触发至少 1 次"每 120 分额外回合"。这就是这队的爆发核心链：**真珠点火 → 狼尊满分 → 2魂多动**。

## 3. 输出层：强普期间的伤害与资源流

狼尊强化普攻「奖励关：狼尊时刻」（无敌玩家状态内）：
- 100 段弹射、总计 240% 攻击力虚数伤；**带好活时转为同倍率欢愉伤**（吃欢愉度/笑点乘区/双暴，不吃攻击）；
- 每 60 隐藏分伤害 +15%（≤2 层）；
- 期间触发 3 次盲盒；**不能回 SP**。

**盲盒（头号补给盲盒）**：结界内我方每耗 1 SP 按概率触发（100%→20%→4%…），随机 3 选 1：
- 超超超大剑：对血最高目标额外 20% 真实伤害；
- 爆爆爆炸蛋：**回 2 SP**；
- 怪怪怪味豆：**+3 笑点**。
欢愉技（崩坏级伤害演示）重置概率回 100%。

**SP 收支**（这队相对宽松，但强普期不回点）：
- 支出：狼尊强普不回点；战技各 −1；
- 收入：普攻 +1；盲盒爆炸蛋 +2；爻光欢愉技 +1；欢愉主天赋行迹「跟你爆了」终结技后 +1；
- **排轴要点**：结界期内让辅助多普攻/耗点，既触发狼尊盲盒伤害，又靠爆炸蛋回点，维持强普不断点。

## 4. 维持层：续好活，别让强普掉出欢愉形态

好活基础 **2 回合、每份独立计**（见通用机制 §4）。断档 = 强普退回普通虚伤。续期手段：

| 来源 | 效果 |
|---|---|
| 狼尊 2 魂·开大 | 进无敌玩家 → 自身全部增益 +1 回合 |
| 狼尊本体·强普清场 | 每回合首次 → 自身全部增益 +1 回合（需清场 + 新敌入场） |
| ~~爻光行迹「鸿运鳞集」~~ | ⚠️ 2026-11-21 修正：**只延长爻光自己那份好活**（原文主语是爻光），**不能续狼尊**，已移出狼尊续期手段 |
| 每个阿哈时刻结束 | 全队参演角色刷新一轮等量笑点的新好活（这是全队性的，狼尊也拿） |

> 引擎含义：好活是 {笑点数, 剩余回合} 的栈；结算时笑点合并、到期各自移除；"续1回合"= 对该角色栈内全份剩余 +1。**狼尊的栈只能被狼尊自己的 2 魂/强普清场续，或被阿哈时刻重发——不要让爻光的续期作用到狼尊栈上**。这是这队能否 0T 的判定命门。

## 5. 一整轮的时序骨架（概念示意，非逐帧）

```
[阿哈1] 解控→真珠(104)挂+40%→爻光(116)易伤→欢愉主(120)→狼尊(999)吃满
        → 全队获好活(笑点等量,2回合), 笑点清零
[行动] 爻光战技结界(+3笑点/动) · 欢愉主攻击(+3笑点) · 狼尊战技(+5笑点/+5隐藏分)
[阿哈2 / 爻光终结技额外阿哈] 固定40笑点 → 狼尊隐藏分 +40(笑点)+40(行迹)=+80
[真珠终结技] 狼尊行动提前30%+额外回合(+120笑点→+120隐藏分)
[狼尊开大] 隐藏分满 → 无敌玩家 → 2魂续好活 → 3→5动强普 → 盲盒回点伤害
[强普期] 辅助耗点触发盲盒(伤害+回点), 盯好活倒计时, 断档前靠阿哈/续期补
[循环] 好活到期前再攒笑点 → 下一阿哈时刻 → 重复
```
