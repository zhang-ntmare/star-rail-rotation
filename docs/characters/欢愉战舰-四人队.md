## 2. 四人协同链（这就是要排的"轴"）

```
【启动 / 充能层】—— 目标是尽快把狼尊隐藏分堆到 60 开大
  爻光战技结界：普攻/战技产笑点（全队共享）
  欢愉主天赋：攻击后回 10 能 + 3 笑点
  狼尊战技：+5 笑点 = +5 隐藏分
  狼尊欢愉技（常态）：+15 隐藏分
        ↓ 笑点累积 → 阿哈时刻（全队欢愉技）
  爻光 1 魂终结技：额外阿哈时刻，固定 40 笑点 → 狼尊 +40（笑点）+40（行迹）= 80 隐藏分

【爆发层】—— 狼尊开大进无敌玩家
  真珠 2 魂终结技：指定狼尊为美学底本 → 行动提前 30% + 额外回合
                    → 额外回合给 120 笑点（2 魂翻倍）→ 狼尊隐藏分直接拉满
  欢愉主终结技：指定狼尊 → 暴伤 +50%（3 回合；BWIKI 正式服，前瞻图 54%）+ 立即放欢愉技（+15 隐藏分）+ 好活 +10
  狼尊终结技：进无敌玩家（行动提前 100%）+ 结界 + 3 次强化普攻
        ↓
  狼尊强普：100 段弹射 + 3 次盲盒；队友每耗 1 SP 再触发盲盒
        ↓
【维持层】—— 续好活，让强普保持欢愉伤害形态
  路径 A（本体）：强普清场 → 每回合首次延长全部增益 1 回合
  路径 B（狼尊 2 魂）：开大进无敌玩家 → 全部增益 +1 回合
  真珠好活盾：全队承伤 60% 由好活池抵挡（1 好活=200 抵御，上限 50）
  真珠战技/强普：回血 + 解控

【资源循环】
  盲盒「爆炸蛋」回 2 SP｜爻光欢愉技回 1 SP｜欢愉主终结技回 1 SP｜狼尊强普不回 SP
  → 这队 SP 相对宽松，但狼尊强普期间不能回点，需在轴中安排回点动作
```

## 3. 排轴视角的关键节点（引擎要实现的能力）

按对引擎设计的影响排序：

| 优先级 | 机制 | 引擎需支持 |
|---|---|---|
| P0 | 额外回合 / 行动提前 100%（狼尊大招、真珠底本） | AV 归零 vs 插入额外行动要区分；狼尊自拉条 ≠ 额外回合 |
| P0 | 阿哈时刻（阿哈作为独立行动条实体） | 全队欢愉技依次施放，按参演编号排序（狼尊 999 最后放吃满 buff） |
| P0 | 笑点 → 隐藏分 → 双暴（动态面板） | 隐藏分是状态变量，实时改变暴击/爆伤，不是固定面板 |
| P0 | 续好活（增益延长 1 回合） | buff 剩余回合可延长；"自身全部增益"批量 +1 |
| P1 | 好活抵挡池（全队共享） | 资源池建模，受击时按 60% 抵扣，上限 50 点 |
| P1 | 盲盒（按全队耗 SP 次数触发，概率递减） | 事件触发 + 概率序列 100%→20%→4% |
| P1 | 额外阿哈时刻（爻光 1 魂固定 40 笑点） | 不消耗现有笑点的额外全队欢愉技 |
| P2 | 欢愉度转模（速度/攻击/防御 → 欢愉度） | 面板推导：狼尊速度转、真珠防御转、欢愉主攻击转 |

## 4. 待验证（影响这队能否算准）

1. **好活当赏的持续回合数与消耗规则** —— 续好活机制的前提，各攻略未给精确值。
2. **笑点的累积阈值**（阿哈时刻触发需要多少笑点）—— 决定阿哈在行动条上何时出现。
3. **隐藏分上限口径**（300 vs 240/2魂+120）—— 决定狼尊能攒多少再开大。
4. **狼尊/爻光/真珠的精确倍率与基础属性** —— 从 StarRailRes 结构化 JSON 补（本环境 curl 不通，需换通路）。
5. **菇菇嘎嘎历险记（三人携带）的确切数值** —— 影响欢愉度/易伤。
6. **缺专武的影响** —— 爻光/真珠/欢愉主都带下位光锥，回能/速度是否够"首动开大/3 动 1 大"要实测。
