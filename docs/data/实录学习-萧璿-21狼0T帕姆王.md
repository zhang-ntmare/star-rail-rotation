> 来源：抖音 @萧璿（崩铁），视频 ID 7698399688068808346（v.douyin.com/OjYAyp_tAXU），时长 4:30，2026-11-22 学习。
> 配置：**2魂狼尊 + 2魂真珠 + 0魂爻光 + 欢愉主 = 9金（up主称可压到 8 金）**——比我们只少 1 魂爻光，是最接近基准队的参考解。
> 关卡：王棋战意汹涌，三波：虚构集合体 → 甜猿泰山 → 合金机铠·帕姆王（85级），0T 完成。
> 学习方式：语音解说 ASR 全文（这条真有解说）+ 270 帧（1fps）帧读 + 内嵌字幕核对。

## ⭐ 解说原文钉死的轴规则（逐条，ASR 有错别字已校正）

1. **开局**：「开局全员正常行动，等待第一个阿哈」——不做花活，普攻战技攒笑点，等阿哈①。
2. **爻光开大充满真珠能量**（字幕原文，00爻照样这么打）：爻光第一轮就开大 → 艺术壁垒 90 能 + 充能绳 → 真珠满能量 → 与绯绯狐实录互证。
3. **真珠首轮点火直接给狼尊**（字幕：「爻光开大充满真珠能量，真珠大招给到狼尊」）：up主没有像代练通文章说的"首轮别给狼尊"——阿哈①转完好活狼尊隐藏分已够，首轮就点火开大爆发。
4. **狼尊开大衔接**：「三面狼尊将剩下的强普打完后立马接上大招，因为三面需要将银狼第二个大招快速打完，这样正好可以让狼尊利用 2 命联动」——强普打空 → 立刻再开大，不给 boss 喘息。
5. **真珠第二发大绑定敌方动作**：「珍珠大招等到帕姆王开启机制后再开」——点火窗口跟 boss 机制走（等帕姆王进机制/劳动最快乐阶段），不是纯按自己能量 CD。
6. ⭐ **up主自我复盘的失误（最有教学价值）**：「这里是一个重大失误，**应该等到阿哈结束，充满欢愉主大招，利用欢愉主大招为狼尊补充隐藏分后再开**（真珠点火），这样正好可以触发 2 命额外回合」→ 正确链序 = **阿哈结束 → 欢愉主大招（+50 暴伤罩 + 隐藏分）→ 真珠点火 → 狼尊开大 → 2 命额外回合**。up主放早了但斩杀线够，无伤大雅。
7. **盲盒触发细节**：「摇光战技触发狼尊盲盒」「珍珠回合释放战技，但不能触发盲盒」「主角这里能触发盲盒最好，没触发问题不大，交由狼尊回合收尾」——波次盲盒由**欢愉技**触发（战技点不触发），真珠的战技不算。
8. **真珠手法**：「真珠特有的水枪小连招，连续小水枪压低帕姆的穴位」——强普连发削韧压帕姆王韧性条；「爻光由于全面的受击，这里可以充当打手」（被集火 → 受击回能 → 多开大）。

## 王棋战意汹涌机制（画面坐实）

- toast 原文：「**战意值已达 100%，即将进入『战意汹涌』阶段**」——战意是敌方资源，涨满 boss 进强化阶段；打完一波后「战意复归」重置重新涨。
- 积分三波累计：26360 → 47200 → 62400+；总伤害显示与积分联动。
- 「奖励关：狼尊时刻」toast——王棋在特定节点进奖励关（狼尊爆发窗口）。
- 实测伤害：狼尊强普单段暴击 ≈ **9.8 万×多段**（满 buff 窗口内），终结斩杀段把 boss 从 10% 直接打穿。

## 对我们队的适用性

- 我们 = 这套配置 + 爻光 1 魂（额外阿哈时刻固定 40 笑点）→ 链序更顺、阿哈更多，**轴只赚不亏**。
- 差异点：我们爻光 1 魂开大本身产阿哈 → 爻光开大时点要尽量卡在全队笑点峰值后，让额外阿哈吃到最多笑点。
- 我们真珠 2 魂同款：点火 = 全体拉条 + 120 笑点额外回合，up 主的「欢愉主大招垫在点火前」规则直接沿用。
