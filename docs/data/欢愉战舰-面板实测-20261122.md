> Mihomo 的 `elation_dmg` 只统计装备/行迹静态节点，**速度/防御/攻击→欢愉度的大转模全部不在面板里**——与"隐藏分转双暴不入面板"同款处理。
> 引擎必须把行迹转模作为**局内动态欢愉度**自行叠加，面板值只是底数。

**战斗内欢愉度总账（全队配置，节点一选【魔法时间】）**：

```
狼尊 = 18% + 138%(行迹) + 60%(真珠1魂) + 60%(魔法时间) + 20%(欢愉主秘技)
      + 爻光结界加成(爻光实战欢愉度×20%)
爻光 = 30% + 97%(行迹) + 60% + 60% + 20% ≈ 267% → 结界给全队 ≈ +53%
狼尊实战 ≈ 18+138+60+60+20+53 ≈ 349% → (1+欢愉度) ≈ 4.49
```

- 双爆实战值：狼尊 82.9/107.4 + 朋克洛德 40%/80% 档(+20%/+32%，欢愉度远超即常驻) + 隐藏分转化（每点0.4%暴击，满后转0.8%爆伤）。隐藏分 120 时 ≈ 满暴 + 爆伤 ~221%。
- **面板暴伤 107.4% 偏低**（狼尊堆速优先），实战爆伤大头来自隐藏分转化和朋克洛德——引擎建模时双爆区必须动态算，不能读面板。
