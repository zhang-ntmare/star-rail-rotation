## 二、⭐ 本轮新挖到的乘区参数（之前一直缺）

### 2.1 坚防守备（星启档）— 拆包 `boss/3022.json` level[4]

```json
{"name":"坚防守备",
 "desc":"首领受到的伤害降低#1[i]%。弱点击破后，行动额外延后，受到的伤害提高#2[i]%。",
 "param":[0.6, 1.25, 1], "param_fix":[0.5, 1, 1.5], "difficulty":4}
```

- 星启档 `param=[0.6, 1.25, 1]`；普通四档（level[0..3]）为 `[0.5, 1, 1.5]`。
- 按帕姆王既有口径反推 🟡：星启档 = **受伤 ×0.4（减伤 60%）**、**破韧后 ×2.25（+125%）**；第三项 `1`（延后参数）语义未定 🟡。
- 对照：帕姆王用普通档 `[0.5,1,1.5]` = ×0.5 / ×2.0，已由实测坐实 → 本口径反推可信但未经银枝帧证。
- **与末法余烬叠加**：环境 buff「战技 +25% / 欢愉 +15%」常驻（拆包 `param=[0.25,0.15]` 实锤）。

### 2.2 众星拱卫 — 拆包 `boss/3022.json`

```json
{"name":"众星拱卫",
 "desc":"除首领外，每多1个敌方单位，敌方全体受伤降低、造成伤害提高。",
 "param":[0.25], "skill_id":302401325, "param_fix":[0.05, 0.03]}
```

- 原文 + Alioth 交叉：每多 1 雕塑 → 敌方全体**受伤 −5%**、造成伤害 +（0.03=3%？🟡档位未定）；每消灭 1 雕塑 → 我方全体伤害 +5%。
- 排轴含义：清雕塑是双向收益（削敌方减伤＋吃我方增伤），且**解韧性保护/不可选中**的前置。

### 2.3 破竹之势（银枝击破奖励）— 拆包原文

> 银骑士受到的伤害大幅降低，但被弱点击破后，**行动额外延后**、受到的伤害**额外提高**，同时使我方全体**恢复战技点并激活终结技**。

- 与全局【末法余烬】"击破坚防守备→全队解控＋激活终结技"叠加。
- ⚠️ 注意区分：节点二（死龙）的三选一 buff 也叫【破竹之势】（终结技后破韧效率+100%/暴伤+40%），**同名不同物**，别混。

### 2.4 三战斗姿态（拆包 `70000303`）

- 【骑士之怒】召【枪尖】：自身受伤降低；**4 个枪尖在场 → 韧性保护**（打不动韧条）
- 【黄金奉还】召【盾】：自身造成伤害提高；盾**嘲讽对位我方角色、并按目标改弱点属性**
- 【瑰丽之勋】召【授勋】：**有雕塑在场时首领不可选中**
