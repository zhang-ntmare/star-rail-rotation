## 7. AV 消耗机制：实测证据 + 假说（🟡 待一倍速录像终裁）

**实测证据（自动档 267 帧）**：
- 60s~165s 我方疯狂出手，AV 恒 1936 冻结 → **我方出手不扣池**
- AV 变化只发生在敌方行动附近，扣块 34/30/46/4/3
- 结算：分数 = 2000 + 剩余 AV，全场敌方总共只扣了 117 AV

**当前最强假说**：AV 池 = 敌方侧行动条推进的记账。敌方单位行动时按其速度/条进度扣；我方拉条、额外回合、翁瓦克进场条全部免费。推论：
- **对面的速度**决定池子烧多快（boss 177 速一动理论 ≈56.5 AV）
- **我们的速度**决定池子烧完前我方总动数（每动消耗 = 10000/SPD）
- **破韧「行动额外延后」= 把 boss 行动条推回去 = 少扣池 = 直接加分**——这就是"剩余行动值就是排轴的意义"的机制底座
- 🟡 扣块 34/30/46 与 boss 周期 56.5 对不上：疑按"敌方条从上次位置走到满的剩余"扣（拉条/延后会改变扣量），待一倍速录像盯 AV 跳变时刻终裁

**社区口径 "x 行动值 x 动"**：给定 AV 预算 x，角色出手次数 ≈ floor(x ÷ (10000/SPD)) + 首动进场条折扣修正。

### 9.2 关键发现：AV 消耗的"正式回合制"模型（v0.9，两局互证）

- **boss 技能事件两局都是 5 次**（auto 4:27 快打 = 5 次，weak 8:21 慢打 = 5 次）→ **拖时间不会让 boss 多出手**，帕姆王行动是**配额/脚本制**，不是纯行动条制。
- **扣 AV 的疑似只有两类**：①boss 首动 ~31-34（auto=风暴就是喧嚣 −34，weak=高温消毒模式 −31，**首动技能不固定**）；②后期大招 ~46（weak=扫除 −46@378s；auto −46@215s 疑同源）。
- **插入技不扣 AV 的强证据**：weak 局 P2 的泼脏水@260s、无死角洗涤@352s 落在 AV 冻结区间（261-377s 逐帧可见 1935 不动）；f0031 boss 特写旁现「额外行动」字样。泼脏水/无死角洗涤/强效肥皂泡疑全部为**免费插入演出**。
- 小怪轮次扣零头（1~10/次，累计 ~26-40）。
- **三局总扣量**：auto 117 / 手动慢打 117 / weak 119 —— 伤害强度、时长、配置对总扣量几乎零影响。
- 13金 3967 分局总扣 33 → 那是**在 boss 把正式回合打完之前就杀掉了**。
- ⭐ **提分路线修正**：分数提升不靠"拖住 boss"（配额制拖不住也不扣分），而是**抢在 boss 第二次正式回合（−46 那次）之前击杀**。auto 3883 → 若砍掉 −46 = 理论 3929；实战轴 3900 目标 = 收尾段提速压掉这一次出手。
