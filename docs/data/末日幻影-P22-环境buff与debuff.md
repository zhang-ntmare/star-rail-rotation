## 1. 全局 Buff【末法余烬】（已入数据卡）

拆包原文：

> 拥有**【坚防守备】**的敌方目标被**弱点击破**时，使我方全体目标**解除控制状态并激活终结技**。
> 敌方全体目标受到的**战技伤害提高 25%**，**欢愉伤害提高 15%**。

### 1.1 「激活终结技」语义判定（2026-11-22 跨期对比钉死）

**先回答"是不是击破充满能量"：不是。** 022 期文本里**没有任何能量/战技点/行动提前/阿哈字样**——那些效果全是别的期的版本，是查资料时最容易混进来的坑：

| 期 | 击破坚防守备目标的效果 | 敌方增伤 |
|---|---|---|
| 3.4 期（fandom） | 解控 + **恢复战技点** + 激活终结技 | 战技伤 +25% |
| **021 期 支配遗忘**（BWIKI） | 解控 + **行动提前** + **阿哈立即获得一个额外回合（固定计入 10 笑点）** | **终结技**伤 +25% + 欢愉 +15% |
| **022 期 领航冥茫（本期）** | 解控 + **激活终结技**（就这一条） | 战技伤 +25% + 欢愉 +15% |

- **最合理读法**：正常游戏里终结技没有"锁定态"，唯一能被"激活"的门槛就是能量 → **激活 = 终结技立即可施放（免能量）**，与社区攻略口径"破韧后大招直接开"一致。925g 攻略（同期）原话"击破之时…可以直接激活大招"。
- 🟡 三个细节待实机（10 秒可验）：①免能量 = 本次不要求能量还是能量视为满（开大后看能量条余量）；②激活是否常驻（不放大，下一波破韧是否仍亮）；③对狼尊是否跳过 60 隐藏分门槛（他没能量条）。
- **实战轴的修正**：爻光进场 127/180 + 一次 E 即满 → "一动开大"用不着免能量解释，末法激活真正喂的是**能量不满时的全员（尤其欢愉主/真珠）**和可能的狼尊门槛。
- ⚠️ **矛盾标注**：实录画面 toast「净化！恢复战技点！」与 022 期文本（无恢复战技点）不符——疑为**破晓战队小怪死亡**的固有奖励（非末法余烬），或 BWIKI 文本省略；按"toast 归小怪击杀"暂记。

- `param = [0.25, 0.15]`，即战技 ×1.25、欢愉伤 ×1.15（常驻乘区，敌方受到）。
- **排轴含义**：击破【坚防守备】目标 = 全队解控 + 终结技立刻充满（改出招窗口，不改 AV）；引擎要有"击破触发全队回能/激活"事件钩子。
- ⚠️ 与银枝【破竹之势】的"破韧→我方全体回SP+激活终结技"**叠加**（见三Boss机制详解 §3.3）。

## 3. 污染 Debuff【贪饕污染】（F3/F4 上半，硬机制）

### 3.1 拆包原文

> 被污染的怪物获得了「贪饕」的力量，受到**致命攻击后不会被消灭，而是立即回复一定比例的生命值**。对其造成伤害可不断**压制其生命上限**，压制到一定比例后，可将敌人彻底消灭。

### 3.2 分档参数（`invasion` 字段，F3=2 级 / F4=3 级）

| 项 | F3 上半（level 30223） | **F4 上半（节点一，本次测试）** |
|---|---|---|
| 污染等级 `level` | 2 | **3** |
| `maze_buff_id` | 3034002 | **3034003** |
| `maze_buff_param` | [0.4, 0.2, 1, 1, 0.35] | **[0.65, 0.3, 0.5, 1, 0.5]** |
| `monster_param` | [0.4, 0.4, 1, 1, 0.72] | **[0.6, 0.8, 1, 3, 1.44]** |
| 污染怪物 | 5013052 / 5013042 / 5013072 | 同左（param 不同） |

> **污染怪物身份已确认（2026-11-21 拆包核名）**：5013052=**破晓战队•赤焰**（hp_base 6045，Elite）、5013042=**破晓战队•苍翼**（5115，Elite）、5013072=**破晓战队•灰烬**（6045，Elite）——**污染载体就是破晓战队三精英**，各自带 `param_list`：赤焰 [1,0]、苍翼 []、灰烬 [0,1]。即"打不死回血"机制主要作用在小怪身上，与攻略"先杀小怪解锁弱点"的打法互锁。
> hsr-trend 脚本 `Ku()` 用 `maze_buff_param[1]` 作为污染"比例"（F4 = 0.3，F3 = 0.2），并在卡片标注污染等级与污染怪物 ID。
> ⚠️ 这些 param 的**逐项精确语义拆包文本未给**（哪个是回血比例、哪个是压制速率需实机/一图流确认）；已列待核。**但机制定性确凿**：致命伤不死→回血→持续伤害压制生命上限→压到阈值才可彻底消灭。

### 3.3 排轴含义（对本次测试的影响）
- **斩杀线再改写**：节点一帕姆王上半 F4 带 3 级污染——即使打空血条也不会直接死亡，会回血并进入"压制生命上限"阶段；**"总血 42,587,598"是名义总血，不是实际打完就赢的伤害量**。
- 引擎需要在"血量归零"事件后插入污染分支：回血 → 上限压制计数 → 达阈值才判胜。这与死龙【可负载】是两套独立的"打不死"机制，**别混为一谈**。
- 污染只在上半（帕姆王侧）；下半死龙、星启银枝**不受污染影响**——三节点测试条件不同，需分别配置。

## 4. 与三 Boss 特殊机制的叠加关系（总表）

| 节点 | 全局 buff | 节点自选 buff | Boss 特殊"打不死"机制 | 污染 debuff |
|---|---|---|---|---|
| 节点一 帕姆王 | 末法余烬 | 魔法时间/金钱帝国/魔城陷落 三选一 | 长效抗菌减伤（保姆移除后才破防） | ✅ **3 级贪饕污染** |
| 节点二 死龙 | 末法余烬 | 攻无不克/生机焕发/破竹之势 三选一 | **可负载**（血最低1转负载）+ 死亡的芬芳（提速/回血） | ❌ 无 |
| 节点三 银枝 | 末法余烬 | 膏腴之地/才藻富赡/喜上眉梢 三选一 | 战斗姿态（减伤/增伤/不可选中）+ 破竹之势（击破奖励） | ❌ 无 |

> 测试引擎若只做节点一：必须同时表达 **末法余烬 + 魔法时间(+60%欢愉度) + 帕姆王长效抗菌/保姆 + 3级贪饕污染** 四层，缺一层斩杀线都会错。
