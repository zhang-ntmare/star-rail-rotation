- **BWIKI 词条原文**：「充能值达到 **20** 时可施放强化普攻移除 1 层【长效抗菌】」。

### 1.2 ⚠️ 补记：「劳动最快乐！」链（此前文档完全漏掉）

拆包 `extra` 词条 `501402001` 原文：

> 【劳动最快乐！】：施放**普攻**后触发【锃亮】效果，对攻击目标额外造成**真实伤害并获得笑点**；施放**战技**后触发【洁净】效果，**恢复战技点**。该效果在【劳动最快乐！】持续时间内**最多各触发 1 次**。

**排轴含义**：
- 这是我方被施加的**正向增益 debuff**——阶段2 起，boss 给我方挂"普攻真伤+笑点、战技回SP"的循环奖励。
- 引擎建模：持有【劳动最快乐！】时，我方普攻分支额外真伤 + 笑点 +1（一次性）、战技分支 SP +1（一次性）；需按技能类型触发并各自计数上限 1。
- 与欢愉队**：额外笑点→保姆充能加速→更快破长效抗菌/韧性，正向循环；回SP缓解欢愉队战技点压力。

### 1.3 排轴建模要点
- **合金保姆**：我方笑点驱动的第三方单位，独立行动条、额外回合；引擎需按"笑点产出事件"累计充能。
- **长效抗菌**：减伤层数，保姆强化普攻逐层移除；全移除触发 boss 大量受伤（破防窗口）——影响有效血量曲线。
- **蓄力→延迟释放**：值日准备中… → 下次行动饱和式大扫除，需表达"蓄力中"状态。
- **敌方技能返笑点**：多个技能"使我方获得笑点"，欢愉队测试的核心资源事件。

**建模修正三条**：

2. **杀小怪要过贪饕两段**：污染 3 级**挂小怪身上**（详情页坐实；✅ 自动档实录帧读：**boss 本体图标行没有污染图标，污染只在破晓小怪上**——帕姆王不吃贪饕回血）——致死一刀被救回回血，**消灭破晓成员必须"压生命上限→阈值→彻底消灭"两段**，排轴的"消灭事件"按两段建。
3. **破晓退散=敌方主动行为**：它进敌方行动序列（不是我方攻击直接打断）——引擎要给小怪加"计数满→下次行动退散"状态机。

**✅ 计数条真义（2026-11-22 大人实测 6 图）**：详情页顶部 **"160/160"橙色条 = 小怪的【韧性条】数值 160，被【破晓力场】锁定所以全程不减**（不是计数器！此前的 160 点制推断作废）。真正的退散计数 = 血条旁的 **"x/16" 数字**：普通攻击命中 **+1**（实测：合金保姆强普 +1）、**欢愉伤害 +2**（官方原文；阿哈时刻连段实测从 7/16 跳 13/16）。计满 16 → 小怪下回合施放破晓退散。引擎按 `count += 2 if 欢愉 else 1` 建。

**✅ 保姆强化普攻削韧 = 100（2026-11-22 大人实测）**：boss 韧条 **455/480 → 355/480**——boss 本体韧条上限 480、可正常削减（不像小怪被锁）。此前"强制削减韧性无数值"关闭。

**✅ 转阶段规则（2026-11-22 大人实测）**：P1 血打空后**要等当前行动段结束才切阶段**（狼尊三段强普会打完才转）；**转阶段时狼尊的额外回合疑似被吞**（真珠给的额外回合可能消失，社区同报）——排轴：P1 血近空时先把额外回合消耗掉再压最后一段血。

## 2. 枯茎朽骨的引路人（死龙）——机制最复杂，斩杀线口径特殊

> ⚠️ 此前文档只记了血量/弱点，机制几乎空白。拆包 16 条技能（9 条有原文）——这是本期三关里**最需要专门建模**的一只。

### 2.1 核心状态机（务必按此建模）

```
【濒死梦泡】积累（我方掉血时）──达上限──> 进入【死亡的芬芳】
                                              │
                    ┌─────────────────────────┤
                    │                         │
              每回合结束提速             boss/哀悯长臂受击 → 削减梦泡
                    │                     + 回复我方生命值
                    │                         │
                    └──────梦泡耗尽──────> 解除状态 + boss 直接陷入弱点击破
```

| 状态 | 拆包原文 | 排轴含义 |
|---|---|---|
| **濒死梦泡** | 我方目标生命值降低时积累；达上限使自身进入【死亡的芬芳】 | 敌方"受击计数器"，把输出转成 boss 的加速+易破窗口，非常规韧性条 |
| **死亡的芬芳** | 每回合结束提高**自身速度**；boss 或【哀悯长臂】受击可削减梦泡并**回复我方生命值**；梦泡完全耗尽时解除状态 + boss **直接弱点击破** | ⚠️ boss 速度随回合递增——**行动序列必须动态重算，不能用固定 SPD**；同时是"打它反而回血"的反直觉机制 |
| **可负载** | 目标生命值**最多降至 1 点**，超出当前生命的伤害转为【负载生命值】；受到治疗时**优先回复负载生命值** | 🚨 **斩杀线判定完全改写**：不可能一击打死，伤害会溢出累积成负载；治疗先填负载坑 |
| **负载生命值** | 超出当前生命值的伤害部分，不断累积 | 伤害"存起来"，需持续输出直到负载被清空才能真正击杀 |
| **垂死挣扎** | 累积一定负载后，目标造成伤害和弱点击破效率降低，一定回合后受**致命伤害** | 我方被"软禁"：输出/削韧效率下降 + 回合倒计时斩杀 |
| **淹没光彩的深渊** | **boss 本体没有弱点**；当【哀悯长臂】处于弱点击破状态时，其初始弱点**添加到其他所有敌方目标**，直到其恢复 | ⚠️ 弱点共享：打小怪削韧→给全场敌人（含 boss）临时挂弱点，是破韧的**唯一途径** |
| **腐败反噬** | 【死梦深度】状态下【哀悯长臂】获得该状态：攻击它后攻击者受少量量子【衰亡伤害】 | 反伤机制，攻击小怪需付出生命代价（触发梦泡连锁） |

### 2.3 对排轴/斩杀判定的影响（关键）
1. **速度动态变化**：【死亡的芬芳】每回合结束提速——引擎行动条不能用固定 SPD，必须逐回合更新。
2. **弱点只能通过小怪**：boss 本体无弱点，必须先击破【哀悯长臂】才能给全场挂弱点——行动优先级反转（先打小怪）。
3. **斩杀线 ≠ 总血**：【可负载】让血量降到 1 后转负载，需累计输出穿透负载才能真正击杀；单纯"总血 59,393,868"不是可一击斩杀的线。
4. **治疗优先级改写**：奶量先填负载——真珠（奶/盾）的收益要重估。
5. **回血反制**：打 boss/小怪回我方血（梦泡机制），可能影响"速杀 vs 稳杀"策略。

## 3. 芒寒色正的银骑士（银枝）——姿态切换 + 击破奖励

> 星启新增节点三，机制核心是**三战斗姿态循环**和**破竹之势击破奖励**。

### 3.1 战斗姿态（拆包词条 `70000303` 原文）

> 芒寒色正的银骑士会随着战斗改变自身状态：
> - **【骑士之怒】**：召唤【枪尖】雕塑，自身受到的**所有伤害降低**，有 4 个雕塑在场时自身进入**韧性保护**状态。
> - **【黄金奉还】**：召唤【盾】雕塑，自身造成的**所有伤害提高**。
> - **【瑰丽之勋】**：召唤【授勋】雕塑，有雕塑存在时，自身**不可被选中**。

**排轴含义**：三姿态改变受伤/输出/可选中性——引擎需按姿态切换重算目标可选性与伤害乘区；"不可选中"会改变嘲讽/受击目标分布。

### 3.2 灵魂释放博弈（拆包原文）

> 【灵魂释放】：为召唤的雕塑施加【灵魂释放】。被施加的单位**被消灭**时 → 我方全体附加【灵魂强化】，**提高造成的伤害**；如果被银骑士**回收** → 提高银骑士本回合造成的伤害。

**排轴含义**：雕塑是"抢资源"目标——我方击杀得增伤（利于速杀），boss 回收得增伤（利于拖回合）。二阶段【绝境逆转】灵魂释放选择**所有**雕塑，博弈放大。

### 3.3 破竹之势（击破奖励，与本期全局机制叠加）

> 【破竹之势】：银骑士受到的伤害**大幅降低**，但被弱点击破后，**行动额外延后**、受到的伤害**额外提高**，同时使**我方全体恢复战技点并激活终结技**。

**排轴含义**：
- 与全局【末法余烬】"击破坚防守备目标→全队解控+激活终结技"**叠加**——击破银枝可能同时触发两套全队回能/激活事件。
- 破韧后"行动延后 + 受伤提高"= 破防窗口，引擎要表达"击破→延后行动→乘区提高"三段。
