## 三、贪饕污染（本季入侵机制，节点 1/2 生效）

| 项 | 内容 |
|---|---|
| 等级 | **污染 3 级** |
| 效果 | 被污染的怪物获得「贪饕」力量，**受致命攻击后不被消灭，而是立即回复一定比例生命值**；对其造成伤害可不断**压制其生命上限**，压制到一定比例后可彻底消灭 |
| 数值 | **贪饕生命值 = 最大生命值的 30%** |
| 排轴含义 | 这不是"多打一条血"，是**血量上限被压制的进度条**——击杀时点由压制比例决定，不看单次爆发大小 |
