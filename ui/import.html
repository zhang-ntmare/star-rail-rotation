① 主通道 · UID 查询（Mihomo）

区服：—

输入 UID 拉取游戏内「角色展示」的练度面板，返回已汇总好的最终属性（速度/双暴/攻击等），无需自己组装。 国服（1/2/5 开头）与国际服（6/7/8/9 开头）均支持。需在游戏里开启角色展示。

直连被浏览器拦截？手动粘贴 API 返回的 JSON

在新标签页打开 https://api.mihomo.me/sr_info_parsed/你的UID?lang=cn，复制全部内容粘到下面，再点解析。

② 兜底 · 米游社查自己（本地代理）

代理：未检测

查自己 box（拥有的角色/光锥）+ 练度，可看到没放进角色展示的人。需要米游社 Cookie，且必须跑本地代理 （浏览器直连会被 CORS 拦 + 缺设备头）。Cookie 只在本机内存转发，不落盘、不上传。

注意：米游社接口只给「等级/命座/行迹/光锥」这类养成零件，不给最终战斗面板（攻击/双暴/速度），这部分仍靠上面的 Mihomo 通道。

1
启动代理：python tools/mys_proxy.py
2
从浏览器米游社页面获取 Cookie（F12 → Network → 任意 api-takumi 请求 → 复制 Request Headers 里的 Cookie）
3
粘贴 Cookie，点「查我的角色」。
