# starRailRotation

基于《崩坏：星穹铁道》的排轴器（Action Order / Rotation Planner）。

## 简介

starRailRotation 是一个基于《崩坏：星穹铁道》的**配轴 / 排轴工具**。目标是以角色的**练度**为输入，结合战技点（SP）、能量与增益机制，推演队伍行动顺序与输出循环，辅助配速（speed tuning）与配轴优化。

> **当前进度（v0.1 原型）**：引擎只实现了「行动条（AV=10000/SPD）+ SP 收支」，练度→属性推导、终结技能量循环、增益窗口对齐、欢愉体系机制（笑点/阿哈/好活）均**在调研与规划中，尚未接入引擎**。机制依据已落地 `docs/`，可按角色/队伍查阅。

## 输入：角色练度

支持以下两类输入，可混合使用：

- **练度配置**：角色等级 / 突破、光锥（等级与叠影）、遗器（套装与主副词条）、命座（E0–E6）、行迹（天赋 / 战技 / 终结技等级与额外能力）。
- **数据面板**：直接录入游戏内角色面板数值（速度 SPD、攻击 ATK、双暴 CR/CD、击破特攻 BE、能量恢复效率 ERR 等），跳过推导。

现状：面板数值直接进入 v0.1 引擎做「行动条推进 + 战技点收支」→ 输出行动顺序与 SP 流水。规划中的「练度推导 → 能量循环 → 增益窗口对齐」见 `docs/research/` 的机制文档，未接入引擎。

## 快速开始

排轴器本体是纯前端单页，无需安装任何依赖：

1. 双击 `ui/index.html`，用浏览器打开
2. **（可选）**点顶部「UID 导入面板」拉取练度，把角色的最终速度一键填入槽位
3. 填写/确认角色**速度 SPD**、初始行动条、行动偏好（战技 / 普攻 / 自动）
4. 设置模拟步数、初始战技点与上限
5. 点「开始排轴」，右侧生成行动轴（出手顺序、时刻、SP 收支）与各角色出手统计

配置自动保存在本机浏览器 localStorage，刷新不丢；点「恢复默认」可重置。

## UID 导入面板（v0.2）

双击 `ui/import.html`，或用排轴器顶部入口进入。两条通道：

- **主通道 · Mihomo**：输入 UID → 拉取游戏内角色展示的**最终面板**（速度/双暴/攻击等已汇总好，无需自己组装）。国服（1/2/5 开头）与国际服（6/7/8/9 开头）均支持。纯前端直连；若被浏览器 CORS 拦截，勾选「经本地代理」或手动粘贴 API JSON。
- **兜底 · 米游社（查自己）**：需本地代理 + 自己米游社 Cookie，可看到 box 里所有角色（含未放进展示的），但米游社只给养成零件（等级/命座/行迹/光锥），**不给最终战斗面板**。

启动兜底代理（仅标准库、只监听 127.0.0.1、Cookie 不落盘）：

```bash
python tools/mys_proxy.py
```

通道细节 / 字段映射 / 限制详见 [`docs/uid-import.md`](docs/uid-import.md)。

> 当前引擎（v0.1）仍是**面板直录**模型：导入的是算好的最终速度，不是由遗器词条重新推导。完整「练度推导层」见 `docs/research/`。

## 知识库（knowledge/）

排轴不是"想出来的"，是"把库里的机制全捞出来 + 代进引擎算 + 拿实测验收"。机制依据统一收在 [`knowledge/`](knowledge/README.md)，按**排轴时会问的问题**分九区：

| 区 | 答什么 |
|---|---|
| `00-rules/` | 红线（不许做什么）、排轴前清单、待钉参数总账 |
| `10-basics/` | AV/速度、回能/SP、乘区、击破、buff、韧性、开怪、嘲讽、计分 |
| `20-action/` | 所有拉条算子（光锥/遗器/命座/角色/场地/推条） |
| `30-units/` | 角色机制与数值 |
| `40-enemies/` | 敌方数值、技能序列、行为模型分类 |
| `50-stage/` | 场地 buff / debuff |
| `60-teams/` | 队伍协同、循环骨架、练度输入 |
| `70-runs/` | 实战轴、对账、参考轴（产物层） |
| `80-tools/` | 数据源、字段坑、引擎、复查记录 |

开工前的强制动作（召回，防止"文档里写了但没用上"）：

```bash
python tools/kb/kb.py recall 爻光 能量 普攻
python tools/kb/kb.py recall 帕姆王 韧条 --zone 40-enemies
```
