## ⭐ 四层递进排轴法（全项目骨架）
①定目标函数→②定骨架（双方SPD+进场条，产出 baseline=零拉条唯一解，必须保留）→③加拉条（每个算子写"被谁提前几AV"）→④加机制（boss技能序列/韧性/力场，会返工，正常）→⑤对比优化（凹点≤1）。资源台账横穿四层；机制层是重解约束不是叠buff。
不确定性分账：①算得出的钉死②没测的🟡+判别式③真RNG计入凹点。凹点低是因为②被钉死。
知识库 `knowledge/` 九区只做索引，正文留 `docs/`（唯一权威、零漂移）。开工前 `python tools/kb/kb.py recall 关键词`，治"文档写了没用上"。
